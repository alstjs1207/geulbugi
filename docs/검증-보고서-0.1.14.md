# 예약 발행 시간 · 0.1.14

2026-10-11 · 어댑터 `naver-one-public-ui-v27`.

예약 탭에서 한국 날짜와 10분 단위 시간을 골라 네이버의 공개 발행 설정에 적용합니다. 빠른 날짜 이동, 자주 쓰는 시간 8개, 마지막 성공 시간의 기본값 재사용, 현재 발행 전환을 제공합니다. 최종 발행은 사용자가 네이버 화면에서 실행합니다.

## 자동 검사

전체 **417개 / 31개 파일** 통과. 신규 예약 검사 33개는 아래를 확인합니다.

- 한국 날짜 경계·연말·윤년·다음 기본 시간, 지난 시간·잘못된 날짜·미지원 분 차단.
- 기존 저장·백업 호환, 시간 목록 내보내기·가져오기, 기본 시간과 목록의 동시 저장 병합.
- 네이버 공개 헤더만 사용, 달력의 월·날짜 선택, 시·분 적용 후 확인, 비활성 달력 거부.
- 최종 발행 버튼 미실행, 공개 범위·댓글 설정·본문 보존, 부분 실패의 발행 시간 복원.
- 오래된 문서 요청 거부, 본문 되돌리기 기록 보존, 커서 선택 없는 예약, 사진 지연 로딩 허용.
- 패널 새로고침 중 선택 유지, 다른 글로 이동 시 초기화, 중복 실행 방지, 저장 실패 안내.

근거: `tests/schedule.test.ts`, `tests/publish-time.test.ts`, `tests/schedule-panel.test.tsx`. 네이버 UI 자동 검사는 모의 DOM을 사용합니다.

## 실제 네이버 어댑터 확인

Ego Lite TaskSpace 47에서 기존 사진 업로드 검수 초안을 불러왔습니다. 동일한 소스의 `NativeAdapter`를 브라우저용으로 번들해 글쓰기 프레임에 연결하여 요청을 실행했습니다. 설치된 확장의 사이드 패널 버튼부터 시작하는 검수와는 구별합니다.

- `2026-10-12 09:40` 적용: 네이버 날짜·시·분 표시가 요청과 일치했습니다.
- 발행 설정을 닫았다가 다시 열어도 `2026-10-12 09:40`이 유지됐습니다.
- `2026-11-02 18:50` 적용: 다음 달 이동과 다른 시·분 선택이 일치했습니다.
- 현재 발행으로 전환: 공개 `현재` 라디오 선택을 확인했습니다.
- 각 성공 전후 본문 리비전이 같았습니다. 최초 검사에서는 사진 블록 전체의 동일성도 비교했습니다.
- 최종 발행을 실행하지 않았고 기존 예약 목록의 **2건**도 유지됐습니다. 검수 종료 시 현재 발행 설정으로 복원했습니다.

네이버 헤더 버튼은 열린 설정 레이어에 가려져 고수준 클릭으로 닫을 수 없었습니다. 화면의 빈 영역을 클릭해 닫은 뒤 재열기 검수를 했습니다. 예약 입력 로직에는 이러한 닫기 조작이 필요하지 않습니다.

실제 예약 등록·시간 도달 후 발행·서버 저장 검수는 실행하지 않았습니다. 이 기능은 날짜·시간 설정만 적용합니다.
