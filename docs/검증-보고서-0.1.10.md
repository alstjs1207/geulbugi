# 링크 미리보기 카드 · 0.1.10

2026-10-08 · 어댑터 `naver-one-public-ui-v24`.

내 글 삽입을 썸네일·제목·요약·도메인이 보이는 네이버 링크 카드로 변경했습니다. 빈 본문·빈 문단·공백만 있는 문단의 커서를 사용할 수 있습니다. 문장 중간에서는 커서 앞뒤 원문과 글자 서식을 유지합니다. 제목·본문 키워드가 없으면 등록한 글 목록을 보여 줍니다.

## 자동 검사

`npm run release` 완료: **289개 / 21개 파일** 통과. 타입 검사·프로덕션 빌드·Manifest V3 구조 검사·ZIP 생성도 통과했습니다.

- 카드 위치·주소·제목과 커서 앞뒤 문구·서식·사진·표 보존.
- 빈 문단·공백·BR, placeholder 제외, 키보드로 다른 빈 문단으로 이동한 커서.
- URL 붙여넣기·썸네일 로딩·URL 글자만 native 입력으로 제거. 다른 글자가 선택되면 삭제하지 않음.
- 늦게 갱신되는 native URL 선택을 기다린 후 삭제. 조회 실패의 변경 이력과 복원 경로, 중복 거부 후 직전 undo 유지.
- 모바일·추적 주소의 정규화, 카드 주소 참조 저장·재읽기, 변경된 카드에 오래된 참조를 적용하지 않음. 로컬 참조는 본문 없이 최대 1,000건 저장.
- 기존 여러 문단 서식·인용구·줄바꿈·저장·단축키 회귀 검사.

자동 검사에서는 네이버 UI를 모의 구현합니다. 실제 네이버 결과는 아래에 별도로 기록합니다.

## 실제 네이버 결과

Ego Lite의 같은 TaskSpace 10에서 설치된 0.1.10 확장의 service worker → 콘텐츠 스크립트 → native 어댑터를 실행했습니다. **블로그 편집 도우미 0.1.10 링크 카드 최종 검수 2026-10-08**이라는 별도 초안을 사용했습니다. 내 글 자료와 기존 사용자 초안은 수정하지 않았습니다.

| 확인 항목 | 결과 |
| --- | --- |
| 빈 본문 | 접힌 커서 0에서 썸네일 카드 1개 생성. URL 글자 제거. |
| 문장 중간 | 오프셋 9의 앞뒤 원문·서식을 유지하며 사이에 카드 삽입. |
| 공백 문단 | 공백 3칸의 오프셋 1에서 삽입. 카드 앞 1칸·뒤 2칸과 앞뒤 문단 유지. |
| 기존 카드 뒤 빈 문단 | 첫 카드를 보존하면서 두 번째 카드 삽입. 키보드로 이동한 커서도 확인. |
| 중복 | 이미 삽입한 주소 거부. 본문 리비전과 직전 undo 유지. |
| 정확한 undo | 빈 본문·문장 중간·두 번째 카드 작업의 이전 리비전으로 복원. |
| 서버 임시저장·재열기 | 자동 복구를 건너뛰고 임시저장 목록에서 최종 초안을 선택. 두 카드·제목·원문·공백·리비전·component ID 유지. |
| 저장 후 주소 참조 | 새 콘텐츠 스크립트 세션에서 두 URL 복원. 두 주소 모두 중복 삽입 차단. |
| 실제 이미지 | 두 썸네일의 로딩 완료와 실제 표시 확인. |

네이버의 공개 입력 프레임에 URL을 붙여 넣으면 카드와 URL 글자가 함께 생성됩니다. 확장은 카드 로딩 후 URL 글자만 선택해 지웁니다. 카드의 공개 DOM과 native copy HTML에는 원문 URL 속성이 없으므로, 삽입한 카드의 native component ID·정규 URL·공개 제목/요약/도메인 해시를 별도 로컬 참조에 저장합니다. 참조에는 본문을 저장하지 않으며 네이버 비공개 모델을 읽지 않습니다.

빈 문단으로 이동한 직후 선택 일치 검사가 한 차례 거부됐으며 작업 전 리비전 `6888cc84`로 복원했습니다. 이후 정확한 native URL 선택이 확인될 때까지 최대 2초 기다리도록 보완했습니다. 늦은 선택 갱신의 자동 검사와 최신 확장의 빈 문단 삽입 실기를 통과했습니다.

| 사례 | 삽입 전 → 삽입 후 → 복원 후 리비전 |
| --- | --- |
| 빈 본문 | `4001523d` → `ec32eb7a` → `4001523d` |
| 문장 중간 | `6cc9cea0` → `2d309134` → `6cc9cea0` |
| 두 번째 카드 | `6888cc84` → `a6622d8a` → `6888cc84` |
| 최종 서버 저장본 | 저장 전 `a6622d8a` = 새 세션 재열기 후 `a6622d8a` |

최종 초안에는 두 카드와 검수용 앞뒤 문단을 임시 저장했습니다. 공개 발행은 하지 않았습니다. 이번 실기는 링크 삽입에 집중했으며, 사진 업로드·이동이나 실제 키 조합 전체를 다시 검수한 결과로 집계하지 않습니다.
