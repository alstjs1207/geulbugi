직접 선언은 `vitest: ^4.1.12`로 변경했다. undici는 jsdom의 기존 허용 범위 `^7.25.0`에서 잠금 파일만 갱신했다. 직접 의존성·override·강제 audit fix를 추가하지 않았다. 제품 런타임 패키지 6개의 잠금 항목 전체는 이전과 정확히 같고 Vite·esbuild·jsdom·OpenSpec 및 기타 직접 의존성 버전도 유지됐다. `website/package.json`은 외부 의존성을 선언하지 않는다.

Vitest의 공식 공지는 [인증 없는 mock 등록](https://github.com/vitest-dev/vitest/security/advisories/GHSA-qxg6-89mg-rqv8)과 [Windows 경로 우회](https://github.com/vitest-dev/vitest/security/advisories/GHSA-xp26-3454-mjgp)의 수정 버전을 4.1.12로 명시한다. undici는 7.30.1 이후 추가 보안 수정 6건을 포함하는 [공식 7.30.2 릴리스](https://github.com/nodejs/undici/releases/tag/v7.30.2)를 선택했다. npm audit의 등록 정보와 공식 추가 보안 수정의 범위를 혼동하지 않는다.
