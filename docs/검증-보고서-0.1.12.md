# 0.1.12 카드 지연·본문 삭제 오류 수정

2026-10-11 · 확장 **0.1.12** · 어댑터 **naver-one-public-ui-v25**.

카드 로딩 후 임시 URL을 Shift+ArrowLeft로 선택하고 Backspace로 제거하던 경로를 제거했습니다. 이 과정에서는 네이버의 비동기 선택 상태와 삭제 대상이 어긋날 수 있었습니다. 실패 후 자동 undo도 로딩 사이에 입력한 사용자 글이나 이전 붙여넣기 이력을 소비할 수 있어 링크 요청에 사용하지 않습니다.

네이버 기본 ‘링크 추가’ 창에서 URL을 검색하고 미리보기 제목·썸네일을 기다린 뒤 확인을 한 번 누릅니다. 본문에는 카드만 삽입하며 URL 선택·삭제 키를 보내지 않습니다. 미리보기에 있던 썸네일이 새 카드에서 늦게 나타나면 기다립니다. 확인 전 본문·커서·URL 변경이나 창 닫기를 감지하면 취소합니다. 조회 실패는 해당 링크 창만 닫습니다. 확인 후 결과가 불확실하면 본문을 그대로 두고 재열기를 안내합니다.

## 자동 검사

카드 관련 추가·변경 검사는 8초 미리보기 지연, 새 카드의 늦은 썸네일, URL 변경, 로딩 중 사용자 본문 변경, 네이버 창 취소·기존 창 보호, 실제 입력 영역의 전체 선택, 확인 후 전체 선택 발생, 확인 후 불확실한 삽입, 실패 시 사용자 글·이전 undo 보호를 포함합니다. 기존 검색·빈 커서·원문 보존 검사도 함께 통과했습니다.
