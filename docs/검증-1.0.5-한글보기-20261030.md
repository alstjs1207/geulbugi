# 1.0.5 한 글 보기 블로그의 최근 글 조회 수정

검증일: 2026-10-30 (KST). 제보 주소: https://blog.naver.com/kmini0604_

## 원인

해당 블로그의 공개 PostList HTML은 한 페이지에 게시글 하나를 반환한다. 첫 페이지와 두 번째 페이지는 각각 다른 게시글을 반환하지만 초기 HTML에는 currentPage 이동 링크가 없으며 postBottomTitleListNavigation이 비어 있다. 페이지 이동 목록은 네이버가 이후 JavaScript로 채우는 구조다.

기존 글부기는 HTML의 다음 페이지 링크만 보고 hasMore를 결정했으므로 글 하나를 읽은 뒤 마지막 페이지로 판단했다. 공개 HTML에는 전체보기 글 수 267개와 pagePerPostCount=1 선언이 포함되어 있어 다음 페이지가 있다는 근거를 확인할 수 있다.

## 변경

- 기존 정규 URL 검증과 공개 페이지 링크 판정을 유지한다.
- 본문 밖의 전체보기 글 수와 네이버 페이지 크기 선언을 추가로 읽어 다음 페이지 존재 여부를 판단한다. 스크립트는 실행하지 않고 선언된 숫자만 데이터로 읽는다.
- 본문 안의 유사 헤더·스크립트, 다른 카테고리, 범위를 벗어나거나 충돌하는 페이지 크기는 판단 근거로 사용하지 않는다.
- 최대 10개·최대 10페이지, 중복 제거, 최신순, 실제 마지막 페이지 종료를 유지한다.

## 검증

- 실제 제보 블로그: 익명 조회로 1~10페이지를 요청해 최근 글 10개·고유 URL 10개를 반환했다. 첫 글 224457981987, 열 번째 글 224456703363. 당시 약 3.41초 소요.
- 기존 블로그(msyu1207): 같은 코드로 1~4페이지에서 최근 글 10개·고유 URL 10개를 반환했다. 당시 약 1.67초 소요.
- 실제 검증은 loadRecentBlog와 fetchRecentBlogHtml 코드를 사용했고 DOMParser 환경과 Chrome 메시지 전달만 로컬 모의로 연결했다. 사용자 확장을 교체하는 UI 조작은 수행하지 않았다.
- 회귀 테스트: JavaScript로 생성되는 페이지 이동 목록, 1개씩 10페이지, 글이 3개뿐인 블로그 종료, 마지막 페이지가 페이지 크기보다 작은 경우, 본문 유사 데이터·잘못된 메타데이터 무시.
- npm run release: 46개 테스트 파일·651개 테스트, 타입 검사, 프로덕션 빌드, 패키지 검증, ZIP 생성 모두 통과.
