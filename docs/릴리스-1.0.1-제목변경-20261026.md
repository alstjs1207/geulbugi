# 글부기 1.0.1 스토어 제목 변경 · 2026-10-26

사용자 요청으로 Chrome 웹 스토어 제목을 **글부기 - 네이버 블로그 편집 도우미**로 변경했다. 기존 항목 `gmcaompgkpccmnpcbngeoabbfkgcoabg`에 업데이트를 업로드하고 심사 제출을 완료했다. 제출 직후 상태는 **검토 대기 중**이며, **검토 통과 후 자동 게시** 옵션이 선택된 상태로 제출했다. 공개 제목 변경 완료와 검색 노출 여부는 아직 확인되지 않았다.

## 변경과 검증

- 원본 저장소 `/Users/msyu/study/geulbugi`에서 작업했다. 별도 clone·worktree·임시 서버는 만들지 않았다.
- `public/manifest.json`의 `name`을 요청한 제목으로 바꾸고 `short_name`을 `글부기`로 지정했다. 업데이트 제출을 위해 버전을 1.0.0에서 1.0.1로 올렸다.
- 패키지·잠금 파일·스토어 자료의 이름과 버전 및 제출 상태를 맞췄다. 패키지 검사에서 새 이름을 검증하며 스토어 검사에서 패키지와 제출 자료의 이름 일치도 확인한다.
- `npm run release`: 타입 검사, 45개 파일의 테스트 598개, 빌드, 패키지 구조 검사와 ZIP 생성 모두 통과했다.
- `npm run store:verify`: 이미지 7개, 공개 개인정보처리방침 접근, 버전·이름 및 ZIP 검사를 통과했다. 기본 샌드박스의 DNS 접근 제한으로 첫 실행은 실패했으며 네트워크 접근을 허용한 재실행에서 통과했다.
- 이전 `artifacts/geulbugi-1.0.0.zip`과 파일별 바이트 비교 결과, `manifest.json`만 달라졌다. 차이는 `name`, `short_name`, `version`이며 실행 코드·리소스·권한은 동일하다. ZIP CRC 검사도 통과했다.
- 대시보드 스토어 등록정보에서 패키지 제목 **글부기 - 네이버 블로그 편집 도우미**를 확인했다. 제출 완료 안내 **검토를 위해 확장 프로그램을(를) 제출함**, 알림 **항목을 제출했습니다.**, 상태 **검토 대기 중**을 확인했다.

## 소개 사이트 출시 안내 갱신

후속 사용자 요청으로 `https://geulbugi.vercel.app/`의 출시 안내를 갱신했다. 공개 스토어에서 설치 가능한 버전은 1.0.0이며, 새 제목 업데이트 1.0.1은 여전히 검토 대기 중임을 확인했다.

- 홈페이지와 설치 가이드의 설치 버튼 5개를 기존 공개 스토어 항목으로 연결했다. 버튼 문구를 `Chrome에 추가`로 맞추고 출시 준비·출시 후 안내를 제거했다.
- 홈페이지의 HTML·Open Graph 제목을 `글부기 - 네이버 블로그 편집 도우미`로 갱신했다. 가이드 제목에도 제품의 새 이름을 반영했다.
- HTML 자체에도 공개 설치 링크를 넣어 JavaScript 비활성 상태에서도 설치 버튼이 작동한다.
- 사이트 검사: 4개 페이지, 110개 로컬 참조·갤러리 자료·Vercel 설정 검사 통과. `SITE_URL=https://geulbugi.vercel.app`로 정적 빌드 통과.
- 브라우저에서 홈페이지 3개·가이드 2개 설치 링크와 제목·출시 안내를 확인했다. JavaScript 비활성 상태에서도 링크와 출시 안내가 유지되며, 390px 모바일에서 가로 넘침이 없었다.
- 원본 저장소의 `main`을 통해 연결된 Vercel 자동 배포를 사용한다. 기존 배포의 GitHub `Vercel` 상태가 성공인 것을 확인했다.
