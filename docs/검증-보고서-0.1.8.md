# 0.1.8 사용성 개선 확인

2026-10-07 · 빌드 **0.1.8** · 어댑터 **naver-one-public-ui-v22**.

기능별 테스트 메뉴·시작 버튼·확인 기록·활성화 조건과 재열기 기록 처리를 삭제했습니다. 인용구는 문단 클릭 → 모양 카드 → 현재 문단에 적용으로 사용합니다. 여섯 모양을 패널의 3열 작은 미리보기로 선택하고 현재 문단의 문구를 보여 줍니다.

## 자동 확인

- 자동 검사 **230개 / 17개 파일** 통과.
- 타입·빌드·Manifest V3 패키지·ZIP 검사 통과.
- 첫 사용, 빈 제목·블로그 설정, 이전 기록의 제거와 사용자 자료 보존 확인.
- 글자 선택과 문단 클릭의 구별, 문단 변경·여러 문단 드래그·Unicode·BR 확인.
- 결과 보존, 정확한 undo·자동 복원·무변경 이력 보존·동시 작업 잠금 회귀 확인.

## 실제 네이버 확인

Ego Lite의 기존 전용 새 초안 **블로그 편집 도우미 0.1.7 인용구 검수 2026-10-07**을 사용했습니다. 일반 사용자 초안이나 공개 글은 변경하지 않았습니다. 실제 모양 카드와 적용·되돌리기 버튼을 실행했으며 테스트 시작 요청·기능 활성화 기록은 사용하지 않았습니다.

설정 메뉴는 **내 블로그·프리셋 단축키·줄바꿈 규칙·백업** 네 개입니다. 실제 로컬 저장 자료는 `posts`, `presets`, `schemaVersion`, `settings`만 남았습니다. 프리셋과 사용자 자료는 보존했습니다.

## 유지한 내부 확인과 이번 범위

지원하지 않는 옵션·사진 업로드·사진 로딩·지연 입력·본문 변경을 계속 확인합니다. 잘못 적용하면 자동 복원하고 정확한 원본 복원이 어려우면 추가 편집을 중단합니다. 사용자에게 테스트를 수행하도록 요구하지 않습니다.

이번 네이버 실기는 인용구와 변경된 사용 흐름을 대상으로 합니다. 사진 업로드·이동·실제 키 조합 등의 실기를 새로 통과했다고 주장하지 않습니다. 이전 저장 호환성 결과는 [0.1.7 보고서](검증-보고서-0.1.7.md)에 보존하며 현재 기능 사용 조건으로 쓰지 않습니다.
