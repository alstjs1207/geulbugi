# 글부기 1.0.0 패키지 검증 · 2026-10-22

사용자 요청에 따라 첫 정식 버전 번호를 **1.0.0**으로 지정하고, 기존 Chrome 웹 스토어 항목의 초안 패키지를 갱신했다. **심사 제출과 공개 게시는 실행하지 않았다.**

## 변경 범위

- 루트 `package.json`, `package-lock.json`의 루트 패키지, `public/manifest.json`, 스토어 제출 메타데이터와 현재 버전 안내를 1.0.0으로 통일했다. 사이트 패키지는 이미 1.0.0이다.
- 스토어 개인정보 입력안·심사 안내의 대상 버전, 설치 ZIP·제출 자료 ZIP 경로와 설치 파일 해시를 갱신했다.
- README의 현재 버전을 갱신하고 사이트의 화면 캡처 설명에서는 버전 번호를 생략했다. 원래 0.1.29에서 촬영한 이미지를 1.0.0 캡처로 재표기하지 않았다. 과거 검증 문서와 캡처 출처 기록은 당시 사실대로 보존했다.
- 확장 프로그램의 기능 코드·권한·저장소 식별자·백업 형식은 변경하지 않았다.

## 실제 스토어 초안 확인

- 기존 항목 `gmcaompgkpccmnpcbngeoabbfkgcoabg`에 검증한 ZIP을 업로드했다.
- 패키지 화면에서 **버전 1.0.0 · 상태 초안 · 아직 게시되지 않은 항목**을 확인했다.
- 업로드된 CRX를 다시 내려받아 로컬 ZIP과 비교했다. 15개 실행·리소스 파일이 정확히 일치하며 매니페스트 차이는 Google이 추가한 `update_url`뿐이다. Google 검증 메타데이터도 별도 포함된다.
- 개인정보처리방침 `https://geulbugi.vercel.app/privacy/`, 홈페이지 `https://geulbugi.vercel.app/`, 지원 `https://geulbugi.vercel.app/guide/`가 유지된다.
- 기존 설명·스크린샷·권한 공개 및 심사자 안내는 유지된다. 심사자 안내의 저장된 짧은 본문에는 이전 버전 번호가 없다.
- ‘제출하여 검토받기’는 누르지 않았다.

이번 작업은 버전·패키지 변경 검증이다. 실제 네이버 원고를 이용한 전 기능 실기 검수는 새로 수행하지 않았다. 직전 점검의 범위와 제한은 [출시 전 최종 점검](출시전-최종점검-20261022.md)을 참고한다.

원시 비교 결과와 다운로드한 CRX는 Git에서 제외된 `artifacts/release-1.0.0/`에 보관한다. 저장소 원본에서 직접 작업했으며 작업용 clone·worktree나 임시 서버를 만들지 않았다. 스토어 확인용 브라우저 탭은 종료했다.
