# 0.1.9 여러 줄 선택 개선 확인

2026-10-07 · 빌드 **0.1.9** · 어댑터 **naver-one-public-ui-v23**.

네이버 input buffer의 다중 문단 복제 DOM에서 공개 문단 id와 원문 경계를 읽습니다. 첫 문단의 선택 시작부터 마지막 문단의 선택 끝까지 글자 서식을 적용하며, 정방향·역방향 드래그 모두 지원합니다. 인용구는 선택에 포함된 문단 전체를 하나의 네이버 인용구로 묶습니다. 패널에서 선택한 문단 수와 여러 줄 미리보기를 표시하고 인용구 적용 버튼을 ‘선택 문단에 적용’으로 안내합니다. 사용자 테스트 메뉴·확인 기록·활성화 단계는 없습니다.

## 자동 확인

`npm run release`: 타입 검사, **18파일 · 243개 검사**, 빌드, 패키지 구조 확인, ZIP 생성 통과.

새 회귀 사례에는 세 문단의 부분 선택, 역방향 선택, 동일 문구 구분, BR·빈 문단·NBSP, 중간 문단 변경 감지, 알 수 없는 id·다른 원문·문단 순서 거부, 보호 요소를 건너뛰지 않기, 다중 문단의 혼합 굵기 해제·불필요한 토글 방지, 부분 경계의 서식 보존, 다중 문단 인용구 변환이 포함됩니다.

## Ego Lite 실제 확인

사용자가 허용한 새 전용 초안 **블로그 편집 도우미 0.1.9 여러 줄 선택 검수 2026-10-07**을 만들었습니다. 이 초안과 설치된 확장만 사용했습니다. 기존 개인 초안과 공개 글은 변경하지 않았습니다.

네 문단 중 첫째 문단 offset 16부터 셋째 문단 offset 18까지 실제 마우스로 드래그했습니다. 최초 원본 리비전은 `7b74e12a`입니다. 실제 패널 프리셋·모양 카드·적용·되돌리기 버튼을 사용했습니다.

서식 3종에서 첫째 문단의 선택 전 글자, 셋째 문단의 선택 후 글자, 마지막 보존 문단의 문구·서식을 유지했습니다. 인용구 6종에서는 처음 세 문단의 원문을 그대로 하나의 인용구로 묶고 마지막 보존 문단을 유지했습니다. 지정하지 않은 15px·기울기·굵기를 보존했습니다. 모든 9회 적용을 원본 `7b74e12a`로 정확히 되돌렸습니다.

최종 확인용 초안에 세 문단 말풍선 인용구 예시를 임시 저장했습니다. 최종 리비전은 `989251e7`이며 네이버 공개 DOM에서 인용구 구성 요소 1개·본문 문단 3개·별도 보존 문단 1개를 확인했습니다. 공개 발행은 하지 않았습니다. 실제 드래그 적용과 undo 확인은 개발 중 수행한 검증이며 제품 사용에 요구하는 단계가 아닙니다.

400×850 패널에서 선택한 3개 문단, 여섯 모양, 선택 문단에 적용·되돌리기 버튼을 확인했습니다. footer가 화면 안에 있고 scrollWidth와 innerWidth가 모두 400px이라 가로 넘침이 없습니다.
