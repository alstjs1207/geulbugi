# 개발자용 스마트에디터 ONE 통합 확인 · 0.1.17

이 문서는 개발·배포 품질 확인용입니다. 사용자에게 테스트 시작이나 기능 활성화 절차를 요구하지 않습니다. 제품에는 테스트 메뉴·확인 기록·모양별 잠금이 없습니다.

## 자동 확인

`npm run release`로 타입 검사, 자동 회귀 검사, 빌드, 패키지 구조 검사와 ZIP 생성을 실행합니다. 패키지와 설치 화면의 버전을 확인합니다. 0.1.13의 사진 선택창 무반응 수정은 [사진 업로드 보고서](검증-보고서-0.1.13.md)에 있습니다. 0.1.12의 카드 지연·본문 삭제 수정 범위는 [수정 보고서](검증-보고서-0.1.12.md)에 있습니다. 0.1.11의 자동 검사와 브라우저 검수 범위는 [등록 없는 검색 보고서](검증-보고서-0.1.11.md)에서 확인합니다. 이전 링크 미리보기 범위는 [0.1.10 보고서](검증-보고서-0.1.10.md)에 있습니다.

## 실제 브라우저 확인

사용자가 허용한 새 전용 초안을 사용하며 기존 일반 초안과 공개 글을 변경하지 않습니다. Ego Lite에서 설치한 개발본을 사용합니다. 원문·혼합 글자 서식·링크·사진·캡션·표·여섯 인용구를 포함한 초안을 개발자 확인용으로 준비합니다.

1. 글자를 선택하거나 대상 문단을 클릭합니다.
2. 프리셋·모양·대상을 고르고 실제 적용 버튼을 누릅니다.
3. 선택한 결과와 다른 문단·서식·링크·사진 보존을 확인합니다.
4. 되돌리기로 원래 원문·서식·구조가 복원되는지 확인합니다.
5. 저장 호환성 확인이 필요한 변경은 다시 적용하고 네이버에서 임시저장합니다.
6. 새 편집 세션의 임시저장 목록에서 같은 전용 초안을 선택하고 결과를 비교합니다.

기능별 준비·통과 기록을 저장하거나 기능 잠금을 해제하는 단계는 없습니다. 결과는 개발자의 로컬 보고서와 `artifacts/`에 기록합니다.

## 기록과 범위

0.1.17은 다섯 기능 탭과 설정의 실제 패널 요청, 사진 8장·콜라주·슬라이드·캡션·표가 있는 본문에서 개별 작업과 복합 작업, 서버 임시저장 뒤 새 세션 재열기를 확인했습니다. 전체 474개 자동 검사와 자료 전후 해시 검사를 통과했습니다. [전체 검수 보고서](검증-보고서-0.1.17.md)에 이전 실패와 수정 후 재검수, OS 단축키·도킹 패널·파일 선택창 닫기 등 미확인 경로를 구분합니다.

0.1.16은 설치된 확장의 실제 패널 버튼으로 단일 사진과 콜라주 묶음의 문단 앞뒤 이동, 재생성된 문단의 선택 표시, 반복 요청과 정확한 undo를 확인했습니다. 빈 문단 이동은 직접 런타임 요청으로 확인했습니다. [사진 이동 보고서](검증-보고서-0.1.16.md)에 실제 검수와 자동 검사 범위를 구분해 기록합니다.

0.1.13은 실제 PNG 업로드, 여러 사진의 자동 개별 배치, 문단 앞뒤·빈 문단 삽입, 파일 선택 취소, 명시적인 되돌리기와 전용 초안 저장을 확인합니다. [사진 보고서](검증-보고서-0.1.13.md)에 실제 검수와 자동 검사 범위를 구분해 기록합니다.

0.1.12는 기본 링크 창으로 삽입, 네트워크 지연·시간 초과·사용자 취소, 명시적인 되돌리기와 서버 저장본을 확인했습니다. [수정 보고서](검증-보고서-0.1.12.md)에 근거를 기록합니다.

0.1.11은 실제 검색 216건·20개 결과 누적·0건 안내·미등록 글의 빈 커서 카드 삽입·중복 차단·정확한 undo·서버 저장본의 새 세션 재열기·기존 저장 자료 보존·400px 화면을 확인했습니다. [별도 보고서](검증-보고서-0.1.11.md)에 근거를 기록합니다.

0.1.10의 빈 본문·공백 문단·문장 중간 링크 카드 삽입, 정확한 undo, 두 카드의 서버 임시저장·재열기와 주소 참조 복원을 통과했습니다. [별도 보고서](검증-보고서-0.1.10.md)에 근거와 범위를 기록합니다. 기존 0.1.9 실기 결과는 [확인 보고서](검증-보고서.md)와 `artifacts/multiline-live-0.1.9.json`에 있습니다. 0.1.9에서 세 문단의 부분 선택·역방향 선택·서식 3종·다중 문단 인용구 6종·선택 밖 원문 보존·정확한 undo를 확인합니다. 제품의 사용자 테스트 메뉴는 계속 없습니다. 당시 재실행하지 않은 사진 업로드·이동·실제 키 조합을 0.1.9 결과로 통과 처리하지 않습니다.

기록할 정보는 버전·전용 초안·재현 순서·기대 결과·적용 후 결과·복원 후 리비전·저장본 비교 결과입니다. 제품에 이를 위한 별도 사용자 테스트 화면을 다시 추가하지 않습니다.
