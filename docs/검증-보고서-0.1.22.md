# 실제 설치본 AI 활용 설정 일괄 ON 검수

2026-10-20 · 최종 확장 **0.1.22** · 어댑터 **v39**.

## 검수 경로

Ego Lite의 실제 설치 확장 `joamlchbdjmofanjhnheaimjifngcolc`를 0.1.20에서 0.1.21로 새로고침한 뒤 검수를 시작했다. 발견한 문제를 수정하고 최종 0.1.22를 같은 설치 경로에서 다시 로드했다.

설치 확장의 `sidepanel.html`을 별도 검수 탭으로 열고, 실제 React **AI 활용 설정 일괄 ON** 및 **되돌리기** 버튼의 클릭 → Chrome 런타임 → 백그라운드 → 설치된 네이버 콘텐츠 스크립트 경로로 실행했다. 읽기 전용 snapshot 요청으로 전후 상태를 비교했다. 편집기 어댑터를 네이버 페이지에 주입하지 않았다. 혼합 상태 준비에는 네이버의 기존 사진 AI 토글을 사용했다.

기존 사용자 글을 수정하지 않고 **AI 일괄 ON 설치본 검수 2026-10-20**이라는 전용 초안을 만들었다. 개별 사진 2장, 2장 콜라주, 2장 슬라이드, 본문과 직접 입력한 캡션을 포함한다.

## 발견한 문제와 수정

1. **AI 되돌리기 후 불필요한 편집 차단:** 0.1.21에서 실제 사진·본문 리비전은 복원됐지만 네이버 키보드 이력을 이용한 복원 확인이 실패하여 이후 작업을 차단했다. AI 설정 되돌리기는 각 기본 토글을 저장된 ON/OFF 값으로 복원하고 원래 전체 리비전을 비교하도록 바꿨다. 앞선 본문·캡션의 키보드 이력을 소비하지 않는다. 되돌리기 후 다시 적용·되돌리기도 통과했다.
2. **화면 밖 슬라이드의 사진 로딩이 AI 버튼을 차단:** 서버 임시저장본을 재열면 비활성 슬라이드 이미지의 원본 주소를 자동 확인하지 못하는 경우가 있었다. AI 토글을 모두 확인하면 원본 주소 로딩과 독립적으로 실행하도록 바꿨다. 사진 업로드·자동 확인 작업이 진행 중이면 기다리고, 현재 보이는 본문·사진 속성을 전후 비교한다. 사진 이동·서식 등 다른 기능의 기존 사진 로딩 검증은 유지한다.
