# 0.1.11 등록 없는 내 글 검색 확인

2026-10-08 · 확장 **0.1.11** · 어댑터 **naver-one-public-ui-v24**.

‘내 글 찾기’의 기본 대상을 등록 자료에서 내 블로그의 공개 검색으로 변경했습니다. 블로그 주소를 한 번 설정하면 글을 개별 등록하지 않고 제목·발췌·날짜가 있는 검색 목록에서 미리보기 카드를 삽입합니다. 기존 등록 자료의 로컬 검색·추천·URL 등록·파일 가져오기도 유지합니다.

## 자동 확인

`npm run release`: 타입 검사, **25파일 · 334개 검사**, 빌드, Manifest V3·권한·필수 파일 확인, ZIP 생성 통과. ZIP 무결성 검사도 통과했습니다.

추가한 45개 검사는 공개 검색 HTML, 0건과 형식 오류 구분, 정규 주소·내 블로그 범위, 쿼리 인코딩, 페이지 검증, 익명 요청, 리다이렉트 거부, 12초 제한, 스트리밍 2MB 제한, UTF-8 분할, 등록 자료 없는 검색·삽입, 다음 페이지 중복 제거, 실패 페이지 재시도, 늦은 응답 무시, 블로그 주소 변경, 기존 로컬 검색·추천을 확인합니다. 기존 미리보기·빈 커서·원문 보존 검사도 함께 통과했습니다.
