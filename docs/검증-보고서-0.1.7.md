## 보존과 호환성

- 이전 프리셋의 왼쪽·가운데는 각각 인용구 2·1로 유지합니다. 모양·정렬 미지정 프리셋은 기존 인용구 모양을 유지합니다.
- 모양을 직접 고르면 네이버 모양 기본 정렬을 사용하고 충돌하는 이전 `align`은 제거합니다. 글자 속성은 보존합니다.
- `quoteStyle`은 프리셋 저장·백업과 블록·문서·선택 서명에 포함합니다. 요청과 다른 모양, 다른 인용구의 모양 변경을 실패로 처리합니다.
- 인용구 저장 증거는 모양별로 기록합니다. 다른 모양으로 바꿔 시험하면 이전 모양의 되돌리기 통과 기록을 재사용하지 않습니다.
- v20 증거를 v21로 이관하지 않았습니다. 이전 실기 결과는 [0.1.6 보고서](검증-보고서-0.1.6.md)에 보존했습니다.

## 새 초안 실기 기록

사용자가 “새 초안에서 테스트해”라고 승인한 뒤 **블로그 편집 도우미 0.1.7 인용구 검수 2026-10-07**을 새로 만들었습니다. 설치된 0.1.7 콘텐츠 스크립트와 실제 네이버 공개 도구로 적용했습니다. 2~6번은 패널의 ‘선택 영역에 적용’ 버튼까지 확인했습니다. 각 단계에서 네이버 ‘저장’을 눌렀고, 새 편집 세션의 임시저장 목록에서 동일 제목을 선택해 저장본을 다시 열었습니다. 자동 복구 내용으로 재열기 검증을 대신하지 않았습니다.

## 검수 중 수정한 회귀

- 패널이 속한 창을 메시지에 포함해 다른 Ego Lite 창의 활성 탭으로 연결되는 문제를 수정했습니다. 이전 편집 프레임은 읽기 요청으로 확인한 뒤 건너뛰며, 변경 요청 전송 후 응답을 잃었을 때 다른 프레임에 변경을 재전송하지 않습니다. 연결 회귀 검사 8개를 추가했습니다.
- 네이버 이력에서 출처의 NBSP가 일반 공백으로 바뀌어 복원 서명을 찾지 못하고 이전 글자 서식까지 되돌리는 사례를 발견했습니다. 공백 위치·개수와 글자 서식은 유지하면서 NBSP/일반 공백만 같은 저장 서명으로 비교합니다. 공백 삭제·증가와 글자 서식 손실은 계속 실패합니다. 이전 서식까지 되돌리지 않는 이력 회귀 검사를 추가했습니다.

혼합 서식·링크 포함 문단·강조 배경색의 제한과 사진·단축키 등 다른 기능의 미검증 상태는 유지합니다. 로컬 예시와 모의 공개 도구 테스트는 실제 네이버 저장 증거에 포함하지 않습니다.
