## 복합 작업과 서버 저장

최종 빌드에서 링크 카드 삽입 뒤 부분 서식, 선택 줄바꿈, 콜라주 이동을 순서대로 적용하고 각각 되돌렸습니다. 되돌리기가 앞선 링크 카드와 사진·인용구·표를 보존했습니다.

| 단계 | 리비전 |
| --- | --- |
| 카드 삽입 전 | `e4b6dd11` |
| 카드 삽입 | `b2f6729c` |
| 부분 서식 → undo | `59ce7e4b` → `b2f6729c` |
| 선택 줄바꿈 → undo | `531db792` → `b2f6729c` |
| 콜라주 이동 → undo | `5425290` → `b2f6729c` |
| 네이버 서버 임시저장 → 새 세션 재열기 | `b2f6729c` → `b2f6729c` |

재열기에서 새 `sessionId`, 사진 블록 **5개 / 실제 이미지 8장**, 표 **2개**, 링크 카드 **1개**, 원래 캡션과 일반 링크를 확인했습니다. 기존 일반 초안·공개 글·예약 1건은 변경하지 않았고 최종 발행은 실행하지 않았습니다. 검수용 초안만 임시저장 목록에 남겼습니다.

검수 전후 사용자 설정·프리셋·저장 글 5개 전체를 원래 상태로 복원하고 직렬화 SHA-256 일치를 확인했습니다.

## 자동 검사와 미확인 범위

자동 검사에는 사진 DnD·묶음 분리/재결합 이력·커서 SVG·정렬 복원, 실제 input buffer 선택 해제·Enter 보호, 초기 링크 조회 경쟁, 사용자 편집 보호, 범위를 넘는 undo/redo, 지연 사진 재로딩과 실제 주소 변경 차단, 비동기 규칙·단축키 저장이 포함됩니다. 네이버 UI 응답과 Chrome API를 모의 구현한 검사는 실제 네이버 실기와 구분합니다.

OS가 보내는 실제 Chrome 키 조합, 브라우저에 도킹된 사이드 패널, OS 파일 선택창의 Escape 닫기는 이번 실기에서 확인하지 못했습니다. 네이티브 앱 창 조회 지연과 `noWindowsAvailable`로 해당 경로를 진행할 수 없었으며 통과로 처리하지 않았습니다. 단축키 슬롯 저장은 실제 설치 패널에서 확인했습니다. 400px 확인은 패널 페이지의 뷰포트 검사입니다. 모든 사진 형식·20장 최대치·용량 초과·느린 네트워크·편집 중 사용자 개입 등의 경계 사례는 자동 검사 또는 이전 버전 실기에 해당합니다.

발행 설정 창을 닫기 위한 메인 발행 버튼 클릭은 자동 승인 검토에서 공개 발행 위험으로 거부되어 실행하지 않았습니다. Escape로 설정 창을 닫고 본문과 이전 undo가 유지되는 것을 확인했습니다. 예약의 최종 발행은 검사 범위에 포함하지 않습니다.
