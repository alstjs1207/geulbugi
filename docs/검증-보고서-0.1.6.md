## 색상·정렬 오류 수정

- 설치된 프리셋 편집창에서 지원 글자색 **71개**, `#1c5cf2` 항목이 없음을 확인했습니다. 글자색·배경색은 같은 네이버 기본 팔레트로 선택하며 임의 HEX 입력은 없습니다.
- 기존 사용자 미지원 값은 임의 치환하지 않고 수정 경로를 표시합니다. 저장·적용·백업 가져오기 전에 검사하며, 과거 내장 기본 색상만 지원 값으로 이관합니다.
- 정렬 열기/닫기 상태와 연결된 메뉴 범위를 읽고 최대 2초 옵션 표시를 기다립니다. 중첩 옵션·떠 있는 도구 중복을 처리합니다. 글자 서식 변경 전에 정렬을 확인하고 이미 같은 값은 생략합니다.
- 왼쪽 정렬의 전체 저장 사이클과 오른쪽 정렬 적용·복원을 실제 확인했습니다. 직접 메뉴를 연 시험에서는 패널 전환 후 선택이 커서로 바뀌어 재선택했습니다. 열린 메뉴 재사용·지연 표시·옵션 중복 경로는 자동 회귀 검사 통과이며, 해당 전체 조합을 실제 통과했다고 표시하지 않습니다.
- 동일한 일반 서식 재요청과 본문 무변경 실패는 기존 되돌리기를 잃지 않습니다. 실제 동일 서식 재요청 후 복원을 확인했습니다.

## 이번 재검수에서 추가 수정한 문제

1. **실제 URL 링크 뒤에 늦게 생기는 미리보기 카드:** HTML 앵커 붙여넣기가 나중에 OpenGraph 카드를 만들었습니다. 제목 span만 붙여넣고 정확히 해당 제목을 Native 선택한 뒤 공개 글자 링크 도구로 URL을 입력합니다. 입력 포커스·InputEvent·입력창 범위의 버튼을 확인하고 제목·href·안정된 리비전을 대기합니다.
2. **붙여넣은 제목 선택과 오래된 본문 앵커 불일치:** 새로 넣은 제목의 확인된 오프셋과 Native 입력 버퍼의 실제 선택 문구가 일치할 때만 범위를 연결합니다. 본문의 임의 다른 글자를 링크로 만들지 않습니다.
3. **문단 끝 커서가 이전 클릭 위치로 덮어써짐:** 메인 문서의 선택 이벤트가 실제 Native 커서를 오래된 DOM 위치로 바꾸지 않게 했습니다. 키 이벤트와 커서 표시 갱신의 시차도 있어 링크 실행 직전에 선택을 다시 읽습니다.
4. **저장 후 제목 공백 때문에 거짓 재열기 실패:** 네이버가 제목 NBSP를 일반 공백으로 바꾸는 것을 같은 제목으로 읽습니다. 본문 문구는 임의 정규화해 검증을 통과시키지 않습니다.
5. **열린 게시글의 발췌가 빈 문자열:** 네이버 뷰어의 바깥 `table.post-body`를 본문 안 표로 오인했습니다. 제외 요소가 실제 본문 내부인지 확인합니다.
6. **카테고리·작성자·메뉴를 함께 수집한 제목과 사이드바 날짜:** 실제 제목 문단을 우선하고 현재 글의 태그 목록과 날짜 범위만 읽습니다. 상대 날짜만 있으면 미등록으로 남깁니다.
7. **사진 창이 자동으로 안 열려도 열린 것처럼 안내:** 사진 위치 지정 후 창이 열리지 않으면 네이버 도구막대의 사진을 직접 누르도록 안내를 보완했습니다. 실제 네이버 버튼으로 파일 선택 창 열기·취소, 패널 대기 취소와 본문 무변경을 확인했습니다.
8. **확장 갱신 뒤 오래된 탭의 문맥 오류:** 문맥이 무효화된 탭의 상태 알림 실패를 처리했습니다. 갱신한 코드의 시험은 새 글쓰기 세션에서 수행했습니다.

검수 자동화도 브라우저 도구막대 새로고침과 확장 카드 새로고침을 구별하도록 수정했습니다. 이전 코드로 수행한 중간 시험은 최종 통과 근거로 사용하지 않습니다. 최신 코드에서 새 세션으로 네 가지 기능을 다시 검증했습니다.
