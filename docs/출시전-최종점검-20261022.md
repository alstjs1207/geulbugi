# 글부기 출시 전 최종 점검 · 2026-10-22

대상 버전: **0.1.29**. 이번 변경은 개인정보처리방침의 공개 주소와 스토어 자료를 정리하는 작업이며, 확장 프로그램 실행 코드는 변경하지 않았다. 심사 제출과 공개 출시는 실행하지 않았다.

## 주소 통합

- 홈페이지: https://geulbugi.vercel.app/
- 사용 안내·지원: https://geulbugi.vercel.app/guide/
- 개인정보처리방침: https://geulbugi.vercel.app/privacy/
- 위 세 주소는 인증 정보 없는 요청에서 HTTP 200을 확인했다.
- 새 처리방침의 1~5항 본문은 확장 패키지의 `privacy.html`과 정확히 일치한다. 제목·헤더·푸터 등 사이트 표시 부분은 다르다.
- 기존 단독 처리방침 사이트는 Sites 접근 권한을 소유자만 허용하는 `custom`으로 변경했다. 비로그인 요청은 HTTP 403이며, 사이트와 소스는 삭제하지 않고 보존했다.
- 스토어의 `submission.json`, 개인정보 입력안, 자료 안내 페이지에 새 주소를 반영했다. 기존 사이트 식별자는 이전 호스팅 기록으로 남겼다.

## 브라우저 점검 범위

최종 `dist/`를 임시 로컬 서버에서 열어 **예시 문서 미리보기**로 확인했다.

- 서식 적용 완료 안내와 되돌리기 완료 안내.
- 인용구 여섯 모양, 내 글 검색·사진 정리·줄바꿈·예약 화면.
- 줄바꿈의 변경 전후 비교, 실제 줄바꿈 위치 표시, 미리보기 취소.
- 예약 날짜·한국 시간 10분 단위·자주 쓰는 시간과 최종 발행 안내.
- 프리셋 단축키 8개 슬롯, 설정 백업 내보내기·가져오기 UI.
- 미리보기 페이지에서 수집한 실행 예외 0건.

이는 실제 네이버 편집기 통합 테스트가 아니다. 이번에는 실제 네이버 원고의 사진 업로드·이동·서식·예약 적용, OS 단축키 입력, 네이버 편집기 지연·재렌더링 조건을 새로 재현하지 않았다. 기존 실기 검수와 모의 회귀 검사는 각 버전의 검증 문서 및 테스트에 별도로 기록되어 있다. 이 미실시 범위를 이번 실기 통과로 간주하지 않는다.

## 출시 시 남은 작업

1. 출시 판단에 필요한 실제 네이버 사용 환경 재확인은 위 범위 제한을 참고한다.
2. 사용자의 별도 출시 지시 후 심사를 제출하고, 승인·게시 상태를 확인한다.
3. 공개 스토어 URL이 유효해지면 `website/site.config.js`의 `chromeWebStoreUrl`을 설정해 설치 버튼을 연결한다. 현재 설치 안내로 연결되는 동작은 출시 전 의도된 상태다.

원시 점검 결과와 내려받은 CRX는 Git에서 제외된 `artifacts/prelaunch-20261022/`에 보관했다. 임시 미리보기 서버와 점검용 브라우저 탭은 종료했다. 작업용 clone이나 worktree는 만들지 않았다.
