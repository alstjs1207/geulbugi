## 실제로 재현해 수정한 문제

1. **전체 줄 선택이 삽입 위치 또는 모호한 선택으로 읽힘:** 네이버 입력 프레임의 빈 `data-input-buffer` 표식과 선택 끝의 독립 FEFF 문자가 섞였습니다. 확인된 빈 시작·끝 표식만 제외하고 본문 span의 실제 문자는 보존합니다.
2. **되돌리기가 원본에 도달하지 못함:** 네이버 선택이 있는 입력 프레임 대신 본문 문서에 명령을 보냈고, 일부 서식은 화면 변화 없는 이력 단계도 만들었습니다. 실제 입력 프레임의 네이버 키 이벤트를 사용하며 명령 소비 여부와 별도로 원본 리비전까지 대조합니다.
3. **글자 크기·정렬 메뉴 선택 실패:** 툴팁을 포함한 크기 문구가 `1616`으로 읽혔고, 떠 있는 선택 도구의 정렬 버튼이 메뉴 옵션과 중복됐습니다. 의미 있는 도구 이름과 네이버 옵션 속성을 읽고 새로 열린 메뉴의 옵션을 선택합니다.
4. **기본 색상 적용 실패:** 이전 기본값 중 일부가 네이버 기본 팔레트에 없었습니다. 실제 지원 색상과 크기만 선택하도록 하고 이전 기본 색상만 이관합니다. 사용자가 지정한 크기·정렬·다른 색상은 유지합니다.
5. **제목·캡션·사진에 따른 거짓 변경 감지:** 편집용 도구 문구와 아직 로딩되지 않은 사진이 본문 결과에 섞였습니다. 제목 문단을 우선 읽고 도구·안내 문구를 제외하며 사진 로딩을 기다립니다. 네이버 일반 링크의 `data-href`도 읽습니다.
6. **인용구 변환 후 속성 보존 실패:** 네이버 변환이 19px·기울기·굵기·색상 등의 기본값을 넣었습니다. 실제 ‘인용구로 변경’과 인용구 스타일 도구로 원래 글자 속성을 맞춥니다. 링크·미검증 혼합 속성과 배경색 변환은 사전 제한합니다. 배경색 보존은 해결 완료가 아니며 결과 검증 조건을 완화하지 않았습니다.
7. **제목 글자만 추가되고 href가 사라짐:** `insertHTML`이 Native 입력 프레임에서 일반 타이핑으로 처리됐습니다. 공개 붙여넣기 이벤트로 바꾸고 네이버의 비동기 링크 처리 완료를 기다립니다. 시간 초과 후 뒤늦은 반영 가능성이 있으면 새 편집을 잠급니다. 실패한 v11 결과는 네이버 undo로 복원하고 저장했습니다.
8. **문단 끝 커서 대신 중간에 링크를 삽입할 위험:** 키보드 이동 후 본문 DOM Selection은 오프셋 15, 실제 Native 커서는 문단 끝 29였습니다. 공개 커서 표시와 글자 경계 좌표를 유일하게 대조하고 삽입 직전 공개 포인터 입력 결과를 확인합니다. 위치가 모호하면 수정 전에 중단합니다.
9. **혼합 굵기 해제가 전체 굵게 적용으로 바뀜:** 네이버 첫 토글이 전체 굵게 적용일 수 있어 결과를 읽고 필요한 경우 다시 해제합니다. 자동 검사는 통과했으나 이 최신 보완의 실제 저장 시험은 대기 중입니다.
10. **줄바꿈이 문서 모델에 반영되지 않을 위험:** Native 입력 프레임의 공개 Enter 이벤트로 변경하고 처리되지 않은 이벤트는 변경 이력으로 세지 않습니다. 수동 공개 경로는 확인했지만 확장 계획 전체 적용은 대기 중입니다.

각 문제의 회귀 검사를 추가했습니다. 자동 검사는 실제 네이버 저장 확인을 대신하지 않습니다.

## 관찰한 연동 제약

1. 네이버 크롬 글쓰기 화면의 공개 도구 이름을 읽기 전용으로 확인했습니다. 이후 사용자가 지정한 초안을 열고 원본의 네이버 임시저장 완료를 확인했습니다. 확장 기능으로 본문을 변경한 결과는 아직 없습니다.
2. 초기 브라우저 연결의 편집기 DOM 검사 경로가 시간 초과됐습니다. 이후 Mac 잠금을 해제한 상태에서 실제 크롬에 개발본을 설치했습니다. 지정한 초안의 새 글쓰기 탭에서도 보조 패널에 ‘편집기에 연결되지 않았어요’가 표시됐습니다. 원인과 읽기 경로 검증은 미완료입니다.
3. 내장 미리보기 브라우저의 JSON 다운로드 완료 이벤트를 확인하지 못했습니다. 콘솔 오류는 없었습니다. 실제 크롬 파일 생성 시험이 필요합니다.
4. 인용구 버튼의 선택 문단 변환, 글자 크기·색상 메뉴 옵션, 정확한 사진 드래그 경로는 현재 후보 어댑터입니다. 해당 옵션을 찾지 못하거나 결과가 다르면 복원을 시도하고 실패 기록을 남깁니다.
5. 표준 편집 명령을 호출했다는 이유로 저장을 성공 처리하지 않습니다. 적용 결과 비교, 되돌리기 확인, 다른 편집기 세션에서 재열기 비교가 모두 필요합니다.
6. 기존 줄바꿈을 없애고 문단을 합치는 옵션과 문장 중간 사진 분할은 네이버 서식·링크 보존 검증 전에는 제한합니다.
7. 현재 인용구 전환은 한 문단 전체 선택으로 시험합니다. 다른 선택 범위 지원은 검증 결과에 따라 확장합니다.
