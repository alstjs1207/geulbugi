# Proposal

## Why
1.1.2 검수에서 지연된 응답의 상태 역전 2종과 저장 대기 중 체크박스 재클릭 유실을 재현했다. 빠르게 드래그·단축키 적용 후 작성하는 흐름에서 반복 본문 읽기와 중복 완료 대기도 확인되어, 원문·사진·직접 입력·undo 검증을 유지하며 개선한다.

## What Changes
- 패널 작업/단축키 응답을 수신 순서와 문서 세션으로 검증한다.
- 설정 조작을 즉시 표시하고 지연·실패 시 마지막 조작을 보존한다.
- 변경 없는 선택의 전체 읽기·알림을 줄이고 긴 문단 caret 후보를 좁힌다. 편집 경계에서는 최신 전체 검증을 유지한다.
- 패널 갱신을 500ms trailing debounce에서 제한된 주기의 갱신으로 바꾼다.
- 서식 뒤 100ms 고정 대기를 제거하고, 전체 적용 검증이 끝난 네이티브 작업만 입력/다음 서식에 제어를 넘긴다. 부분 적용·미확정 요청을 큐에서 재실행하지 않는다.
- 단축키는 매 실행 시 최신 설정을 읽되 저장 글 전체의 불필요한 검증을 피한다.

## Capabilities
### New Capabilities
없음.
### Modified Capabilities
- `panel-shortcuts`: 응답 순서/세션 보존, 연속 입력 시 bounded 갱신.
- `editor-safety`: 검증 완료 후 즉시 작성/다음 적용, 부분 적용·미확정 보호 유지.
- `privacy-storage`: 저장 대기 중 조작 표시와 실패 복원, 기존 저장/백업 호환.

## Impact
`src/ui`, `src/editor`, `src/background.ts`, `src/platform/storage.ts`, 관련 회귀 테스트·성능 계측·OpenSpec 문서. 권한·외부 전송·스토어·공개 발행은 변경하지 않는다. 원본 저장소에서 작업하며 커밋·푸시·스토어 제출은 이번 요청에 포함하지 않는다.
