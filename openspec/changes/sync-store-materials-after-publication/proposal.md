# Proposal: 승인된 1.2.0 문구 반영과 게시 진행

## Why

초기에는 1.1.2 기준 자료를 로컬에 준비하고 게시 후 반영을 보류했다. 2026-11-11 사용자가 업로드한 1.2.0의 문구 수정과 게시 진행을 명시적으로 요청해 기존 조건을 해제했다. 저장·검토 제출·공개 반영을 서로 다른 관측 결과로 관리한다.

## What Changes

- 로컬 소개·개인정보 입력안·상세/요약 심사 안내를 반영 후보로 보존한다.
- 대상 항목의 업로드 1.2.0과 현재 공개 버전을 확인한 후 대시보드의 문구와 로컬 후보를 비교해 필요한 내용만 저장한다.
- 저장 결과·검토 상태·공개 페이지를 구분해 기록하고 확인한 task만 완료 처리한다.
- 기존 1.2.0 패키지로 문구 저장·검토 제출·승인 후 자동 게시 절차를 진행한다. 검토 대기는 공개 완료로 처리하지 않으며 새 ZIP 업로드·기존 심사 취소는 하지 않는다.

## Capabilities

### New Capabilities
없음. 제품 기능·권한·설치 패키지는 유지한다.

### Modified Capabilities
- `release-operations`: RELEASE-002를 최신 명시 승인 범위에 따른 문구 저장·심사 제출·게시 절차로 갱신한다. 기존 보류는 과거 지시로 남긴다. RELEASE-001·RELEASE-004와 `privacy-storage`의 DATA-003은 유지한다.

## Impact

`store/listing-ko.txt`, `store/privacy-fields-ko.txt`, `store/reviewer-instructions-ko.txt`, `store/reviewer-dashboard-ko.txt`, `store/submission.json` 및 대상 항목의 스토어 등록정보·개인정보 보호·테스트 안내가 관련된다. 코드·권한·설치 패키지를 바꾸지 않는다.

## 2026-11-11 Updated Authorization
사용자가 이미 업로드한 1.2.0의 문구 수정과 게시 진행을 명시적으로 요청했다. 이전의 게시 후 반영 조건은 해제한다. 같은 항목의 실제 업로드 버전을 확인하고 필요한 필드 저장·심사 제출·가능한 게시 절차까지 진행하며, 외부 검토 대기와 공개 완료는 구분한다. 이 승인으로 새 ZIP 업로드·기존 심사 취소·권한 또는 계정 변경을 수행하지 않는다.
