# Release Operations Delta

## MODIFIED Requirements

### Requirement: RELEASE-002 승인된 스토어 문구와 게시 절차
운영 작업은 최신 사용자 지시에 따른 대상 버전·문구·게시 범위를 확인하고 해당 범위의 대시보드 저장·심사 제출·게시 절차를 수행해야 한다(SHALL). 저장·제출·공개 게시를 각각 관찰한 근거로 기록하며, Git 커밋·푸시를 외부 작업 승인 또는 완료로 취급하지 않아야 한다(MUST).

#### Scenario: 업로드된 버전의 문구 수정과 게시 승인
- **WHEN** 사용자가 업로드한 1.2.0의 문구 수정 및 게시 진행을 명시적으로 지시한다
- **THEN** 같은 항목의 실제 업로드 버전과 기존 문구를 확인하고 필요한 필드를 저장한 뒤 허용된 심사·게시 절차를 진행한다. 새 ZIP을 임의로 업로드하거나 기존 심사를 취소하지 않고, 검토 대기를 공개 완료로 기록하지 않는다
