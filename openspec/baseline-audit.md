README와 store 자료는 1.1.2로 정리하고 과거 제출 상태를 history로 보존한다. 2026-11-10의 스토어 반영 보류 지시를 active change와 운영 명세에 기록한다. 현재 메타데이터의 공개 버전은 사용자 확인 출처이며 이번 회차에서 대시보드 게시 완료를 새로 확인하지 않았다.

OpenSpec 1.15.0을 개발 의존성에 고정하고 Codex core 스킬 6개, 루트 AGENTS.md, 5개 현재 명세(18개 요구사항), 운영 후속 change와 확인 공백을 추가한다. spec은 현행 코드·회귀 테스트와 사용자 결정을 기반으로 작성한 소급 명세다. 런타임 정책을 새로 변경한 것은 아니다.
