**글부기**는 PC 크롬의 네이버 블로그 글쓰기 화면에서 서식·인용구·내 글 링크·사진 위치·줄바꿈·예약 발행 시간을 관리하는 확장 프로그램입니다. TypeScript · React · Manifest V3로 만들었습니다.

현재 버전은 **0.1.29 · 어댑터 v42**입니다. 내 블로그 주소를 한 번 설정하면 글을 개별 등록하지 않고 공개 글을 검색해 미리보기 카드로 삽입할 수 있습니다. 설치 후 본문에서 대상을 선택하고 바로 적용합니다. 블로그 주소는 내 글 검색 범위에 사용하며 서식·인용구 사용의 선행 조건이 아닙니다.

사용자가 선택한 거북이·연필 가방 원본 그림을 제품 아이콘으로 사용합니다. 0.1.23에서 이름·아이콘·패널·설정·처리방침·스토어 자료를 갱신했고 기존 저장소 키와 백업 형식은 유지합니다.

## 설치

1. [글부기 0.1.29 설치 ZIP](artifacts/geulbugi-0.1.29.zip)의 압축을 풉니다. 개발 중에는 `dist` 폴더를 사용합니다.
2. 크롬 `chrome://extensions`에서 개발자 모드를 켜고 **압축해제된 확장 프로그램을 로드합니다**를 선택합니다.
3. 압축을 푼 폴더 또는 `/Users/msyu/study/geulbugi/dist`를 선택합니다.
4. 네이버 글쓰기 탭을 새로고침하고 확장 아이콘으로 오른쪽 패널을 엽니다.

기존 ZIP 설치를 갱신할 때는 설정 백업을 내보낸 뒤 새 ZIP의 파일을 현재 확장을 로드한 폴더에 교체해 경로를 유지합니다.

기존 개발본을 갱신할 때는 먼저 네이버에서 초안을 임시저장합니다. `chrome://extensions`에서 이 확장의 새로고침 버튼을 눌러 버전 **0.1.29**을 확인한 뒤 글쓰기 탭도 새로고침합니다. 파일만 교체하면 패널은 새 코드, 열린 글쓰기 탭은 이전 코드로 실행될 수 있습니다. 최소 크롬 버전은 116입니다. 설치된 확장에는 개발 서버가 필요하지 않습니다.

## 서식과 인용구

**서식:** 한 줄 또는 여러 줄의 글자를 드래그 → 본문·소제목·강조 프리셋 선택 → **선택 영역에 적용**. 여러 문단의 일부만 드래그해도 첫 문단과 마지막 문단의 선택 경계를 지킵니다. 선택 밖 글자는 유지합니다. 패널에 선택한 문단 수와 문구를 표시합니다.

**인용구:** 본문의 문단 클릭 → 인용구 프리셋 선택 → 모양 카드 선택 → **현재 문단에 적용**. 문단 전체를 드래그하지 않아도 됩니다. 한 문단 안에서 일부 글자만 선택한 경우에도 문단 전체에 적용합니다. 여러 문단을 드래그하면 **선택 문단에 적용**으로 포함된 문단 전체를 하나의 인용구로 묶습니다. 위에서 아래로, 아래에서 위로 드래그 모두 지원합니다.

| 모양 | 이름 |
| --- | --- |
| 1 | 따옴표 |
| 2 | 버티컬 라인 |
| 3 | 말풍선 |
| 4 | 라인&따옴표 |
| 5 | 포스트잇 |
| 6 | 프레임 |

여섯 모양의 작은 미리보기를 패널에서 바로 선택합니다. 선택은 프리셋에 저장되고 **적용**을 눌렀을 때 본문이 바뀝니다. 클릭한 문단 또는 선택 문단들의 문구와 줄바꿈을 미리보기에 표시합니다. 기존 인용구의 모양도 변경할 수 있습니다.

지정하지 않은 글자 속성은 유지합니다. 모양을 고르면 해당 인용구의 기본 정렬을 사용합니다. 이전 프리셋의 왼쪽·가운데 정렬은 각각 2번·1번 모양에 대응합니다. 모양과 정렬을 지정하지 않은 인용구 프리셋은 기존 인용구 모양을 유지합니다.

링크 포함 문단, 보존할 글자 서식이 서로 다른 문단, 배경색을 가진 일반 문단의 인용구 변환은 지원하지 않습니다. 적용 전에 해당 이유를 안내합니다. 글자 크기와 색상은 네이버 메뉴의 지원 값 중에서 선택합니다. 예전 미지원 값은 원래 값을 보존하고 프리셋 수정으로 안내합니다.

프리셋은 추가·수정·삭제할 수 있습니다. 설정의 **프리셋 단축키**에서 8개 슬롯에 프리셋을 연결하고 **크롬에서 키 조합 지정**으로 키를 설정합니다. 4번 슬롯은 기본적으로 인용구입니다. 단축키도 별도의 기능 확인 절차 없이 적용합니다.

## 내 글 링크

설정에서 내 블로그 주소를 한 번 저장합니다. **블로그 검색**에서 검색어를 입력하고 **검색**을 누르거나 현재 글에서 추출한 추천 검색어를 누릅니다. 네이버의 내 블로그 공개 검색 결과에서 제목·발췌·발행일을 읽으며 글을 개별 등록할 필요가 없습니다. **검색 결과 더 보기**로 다음 페이지를 이어서 불러옵니다. 검색 결과는 등록 자료에 자동 저장하지 않으며 비공개 글은 가져오지 않습니다. 검색 실패는 결과 없음과 구별해 안내하고 같은 요청을 다시 시도할 수 있습니다.

본문에 커서를 클릭한 뒤 검색 결과의 **미리보기 삽입**을 누르면 네이버의 링크 카드로 넣습니다. 게시글의 썸네일(있는 경우)·제목·요약·주소를 네이버에서 불러옵니다. 빈 본문, 빈 문단 또는 공백만 있는 문단에도 현재 커서 위치에 넣을 수 있습니다. 문장 중간에서는 커서 앞뒤 글을 나누어 카드를 넣고, 기존 글자와 서식은 유지합니다. 카드와 일반 링크 모두 중복 삽입을 확인합니다. 미리보기는 네이버 링크 추가 창에서 먼저 불러온 뒤 카드만 삽입합니다. 로딩 중 본문·커서가 바뀌면 취소하며, 로딩 실패 시 기존 본문을 자동으로 지우거나 되돌리지 않습니다.

기존 등록 자료는 **저장한 글**에서 제목·태그·발췌로 검색하고 **현재 글 키워드로 추천**을 이용합니다. **내 글 직접 추가 · 파일 가져오기**를 펼치면 URL 등록·열린 내 글 등록·JSON 가져오기를 계속 사용할 수 있습니다. 원문 읽기가 제한되면 제목·태그·발췌를 직접 입력할 수 있습니다.

## 사진 AI 활용 설정

**사진** 탭의 **AI 활용 설정 일괄 ON**을 누르면 현재 글에 들어 있는 모든 사진의 AI 활용 설정을 켭니다. 본문이나 사진을 선택할 필요가 없습니다. 이미 켜진 사진은 유지하며 개별 사진·콜라주·슬라이드 묶음을 함께 처리합니다. 묶음은 네이버의 묶음 토글을 한 번 누르고 포함된 사진 수로 집계합니다. `ON 사진 수 / 전체 사진 수`를 표시합니다.

네이버의 기본 AI 활용 토글로 적용하고 전체 상태를 다시 읽어 확인합니다. 원문·캡션·서식·사진 위치는 유지하며 **되돌리기**로 직전 일괄 변경을 복원할 수 있습니다. 중간에 직접 편집하면 멈추고 현재 ON 수를 안내합니다. 다시 실행하면 남은 OFF 사진만 켭니다. 이후에 새로 추가한 사진에도 적용하려면 버튼을 다시 누릅니다.

사진 업로드·자동 확인 중에는 완료를 기다립니다. 화면 밖 슬라이드 사진의 원본 로딩을 완료하지 못했더라도 AI 토글 상태를 확인하면 일괄 설정을 사용할 수 있습니다. 이전 확장 코드가 열린 글쓰기 탭에 남아 있으면 갱신 방법을 안내합니다.

## 사진 위치

사진과 대상 문단을 고르고 **문단 앞 / 문단 뒤**를 선택한 뒤 **지정 위치로 이동**을 누릅니다. 문단 내용 검색과 현재 커서 근처 이동을 제공합니다. 긴 문서는 소제목별로 묶고 소제목이 없으면 20문단씩 묶습니다.

**새 사진**을 누르면 파일 선택창이 바로 열립니다. 선택한 사진은 지정 문단 앞·뒤에 네이버의 기본 업로드로 추가합니다. 여러 사진은 선택한 순서대로 개별 사진으로 넣으며 한 번에 20장·합계 20MB까지 선택할 수 있습니다. 빈 문단은 본문에서 클릭하고 **현재 커서 근처**를 누르면 대상으로 지정할 수 있습니다.

파일 선택을 취소하면 본문과 직전 되돌리기 기록은 유지됩니다. 선택창을 닫은 후 버튼이 선택 중 상태로 남으면 **사진 선택 취소**를 누릅니다. 사진을 전달한 뒤에는 실제 이미지 주소와 모든 사진의 수량·위치가 확인될 때까지 다음 편집을 기다립니다. 파일 선택 중 본문이나 편집 탭이 바뀌면 사진을 추가하지 않고 위치 재선택을 안내합니다.

네이버의 기본 사진 선택·드래그로 전체 사진 또는 사진 묶음을 이동합니다. 문단 첫 글자 앞·마지막 글자 뒤의 네이버 이동 커서를 확인하고 사진·캡션의 서식·묶음 레이아웃·속성·원문·이동 위치를 비교합니다. 이동 중 네이버가 문단을 새로 만들어도 선택한 문단을 패널에 유지합니다. 이미 같은 위치면 편집하지 않고 직전 되돌리기 기록을 유지합니다. 이동 커서를 확인하지 못하거나 이동 전에 본문이 바뀌면 드래그를 취소합니다.

## 줄바꿈

선택 영역 또는 일반 본문, 문장 수, 긴 문장 기준과 빈 줄 간격을 설정합니다. 기본값인 **문장·구절 우선**은 길이를 참고해 쉼표·연결 구절을 먼저 찾으며, 적절한 경계가 없으면 길이를 넘더라도 원래 문장을 유지합니다. 명사구를 임의의 공백에서 나누지 않으며 인용문·괄호·링크·날짜·숫자는 보호합니다. **길이 우선**을 고르면 이전처럼 기준 길이 근처의 공백에서 나눕니다. 두 방식 모두 원문의 글자와 서식을 유지합니다. 의미 우선은 로컬 규칙에 따른 보수적 분할이며 문맥 전체를 이해하는 AI 분석은 아닙니다. **변경 전후 미리보기**에서 적용할 문단을 고르고 직접 적용합니다. 취소는 본문을 변경하지 않습니다.

소제목·인용구·사진·캡션·표·목록·코드·링크 카드를 제외합니다. 일반 링크와 글자 서식은 유지합니다. 소수점·날짜·URL·인용문·영어 축약어의 예외를 처리합니다. 글자 수는 참고값이며 실제 줄 폭은 네이버 모바일 미리보기에서 확인합니다. 기존 문단 합치기와 줄바꿈 재정리는 실제 네이버 적용을 지원하지 않습니다.

## 예약 발행 설정

**예약** 탭에서 날짜와 시간을 고르고 **예약 설정 적용**을 누릅니다. 네이버 발행 설정을 열어 **예약**을 선택하고 네이버 달력과 시간 목록으로 날짜·시간을 적용합니다. 적용 결과를 다시 읽어 패널에 표시합니다. 네이버 화면에서 확인한 뒤 **발행**을 누르면 예약이 완료됩니다.

- 한국 시간(`Asia/Seoul`)과 네이버의 10분 단위를 사용합니다. 지난 시간과 잘못된 날짜는 적용 전에 안내합니다.
- **오늘 / 내일 / 하루 뒤 / 일주일 뒤**로 날짜를 빠르게 바꿉니다. 하루 뒤·일주일 뒤는 선택한 날짜를 기준으로 이동합니다.
- **시간 저장**으로 자주 쓰는 시간을 최대 8개 저장하고, 시간 옆 ×로 삭제합니다. 마지막으로 성공한 예약 시간을 다음 글의 기본 시간으로 사용합니다. 기본 시간이 이미 지났으면 다음 날로 시작합니다.
- 네이버 발행 설정의 현재 값을 표시하고 **현재 발행으로 전환**도 지원합니다. 사진을 모두 스크롤해 불러오거나 본문 커서를 선택할 필요는 없습니다.
- 네이버 달력의 선택 가능 범위와 비활성 날짜를 따릅니다. 기존 글 수정 등에서 예약 옵션이 없으면 이유를 안내합니다.

제목·본문·사진·캡션·카테고리·공개 범위·태그는 유지합니다. 예약 설정은 본문 되돌리기 기록과 별도로 처리합니다. 적용 실패 시 사용자 조작이나 본문 변경이 없을 때만 발행 시간 설정을 원래대로 돌립니다. 사용자가 중간에 조작하면 현재 상태를 확인하도록 안내합니다.

글쓰기 탭에 이전 확장 코드가 연결돼 있으면 적용 버튼을 비활성화하고 갱신 순서를 안내합니다. **확장 관리 열기**로 해당 확장의 관리 화면을 열 수 있습니다. 일시적으로 연결이 끊겼다가 같은 글쓰기 세션으로 돌아와도 고른 예약 날짜·시간을 유지합니다. 다른 문서나 새 글쓰기 세션에 연결되면 해당 글의 설정으로 시작합니다.

예약 날짜는 글별로 선택하며 자주 쓰는 시간과 기본 시간은 기존 설정·백업에 저장합니다. 네이버 예약 목록의 기존 글을 수정하거나 예약을 취소하는 기능은 포함하지 않습니다.

## 되돌리기와 적용 안내

패널의 **되돌리기**는 직전 작업의 원문·서식·사진 상태까지 복원합니다. 같은 서식을 다시 적용하면 이미 적용됐다고 안내하고 기존 되돌리기 기록을 유지합니다. 이후 사용자가 본문을 변경했다면 그 변경을 덮어쓰지 않습니다.

적용 결과와 요청한 서식을 내부에서 비교합니다. 일반 서식의 잘못된 변경은 자동 복원하며 비동기 링크·사진 삽입 실패는 현재 본문을 그대로 두고 결과 확인을 안내합니다. 사용자가 테스트를 실행하거나 기능을 활성화할 필요는 없습니다. 버튼 위에는 필요한 대상 선택, 사진 로딩 또는 연결 상태만 안내합니다.

- 일반 서식은 적용할 글자를 드래그합니다.
- 인용구는 문단을 클릭하거나 여러 문단을 드래그합니다. 사진·표를 함께 넘는 범위는 본문 문단만 다시 선택해 주세요. 기존 인용구와 다른 문단을 섞은 선택은 나누어 적용합니다.
- 화면 밖 사진은 자동으로 확인한 뒤 원래 스크롤 위치로 돌아옵니다. 직접 입력·클릭·스크롤하면 자동 확인을 멈추며, 멈췄거나 확인에 실패하면 **사진 다시 확인**을 누릅니다. 사진이 없는 글은 바로 사용할 수 있습니다. 사진의 실제 주소·수량·캡션 확인은 편집 전후에 계속 수행합니다.
- 연결되지 않으면 네이버 PC 글쓰기 탭을 열거나 새로고침합니다.

로그인·임시저장·최종 발행은 네이버 화면을 사용합니다. 예약 탭은 발행 시간 설정을 돕고 최종 발행을 실행하지 않습니다.

## 저장과 백업

설정·프리셋·게시글 자료를 이 PC의 `chrome.storage.local`에 저장합니다. 기존 버전의 사용자 설정과 내 글 자료는 유지하며 기능 테스트 기록은 읽거나 저장하지 않습니다.

백업은 프리셋·설정·게시글을 선택해 JSON으로 내보냅니다. 100개를 넘는 사용자 프리셋과 여러 백업을 병합한 자료도 내보낸 뒤 다시 가져올 수 있습니다. 가져오기 전에 건수를 확인하고 기존 설정 유지 또는 교체를 선택합니다. 미지원 프리셋은 자료 변경 전에 수정할 값을 안내합니다. 쿠키·비밀번호·로그인 세션·본문은 백업하지 않습니다.

권한은 `storage`, `sidePanel`과 네이버 블로그 호스트입니다. AI API나 별도 운영 백엔드를 사용하지 않습니다. JSON 가져오기는 20MB, 로컬 저장은 8MB까지 확인합니다.

## 스토어 출시 준비

2026-10-21 사용자 요청에 따라 개인정보처리방침을 공개로 변경했습니다. 로그인 없이 읽을 수 있는 주소는 https://blog-editor-privacy-yuminseon.yu-lotti.chatgpt.site/privacy 입니다. 확장 프로그램의 심사 제출과 공개 출시는 사용자 지시에 따라 계속 보류합니다.

[출시 준비 현황](store/index.html)에 설치 파일, 스크린샷 5장, 홍보 이미지, 소개 문구, 권한 사유와 심사 안내를 모았습니다. 개인정보처리방침은 패널·설정에서 열 수 있으며 배포 파일에 포함합니다. 사용자 설정은 유지합니다.

`npm run store:verify -- --draft`는 제출 자료와 이미지 규격을 검사합니다. `npm run store:verify`는 공개 처리방침 URL과 접근 상태까지 요구합니다. Google 계정 본인 인증·개발자 등록 상태를 확인한 뒤 콘솔에 제출하며, 공개 전 최종 배포 범위를 확인합니다.

0.1.11은 등록 없는 검색, 공개 검색 HTML 읽기, 내 블로그 범위 확인, 다음 페이지, 중복 제거, 실패 재시도, 오래된 응답 무시를 확인하는 검사를 추가했습니다. 자동 검사 334개와 타입·빌드·패키지 검사를 통과했습니다. 실제 네이버의 검색 216건·다음 페이지·미등록 글의 빈 커서 카드 삽입·중복 차단·정확한 undo·서버 임시저장·재열기를 확인했습니다. 기존 설정과 저장 글 5개의 전후 SHA-256도 동일합니다. 이 개발자 확인은 사용자의 기능 사용 조건이 아닙니다.

### 0.1.29 · 편집 신뢰성 문제 6건 수정

1. 되돌리기·다시 실행의 실제 반영을 확인하기 전 다음 취소를 보내지 않습니다. 미확정 명령은 재전송하지 않으며 이전 사용자 서식을 침범한 취소는 다시 실행해 보호합니다.
2. 서식·인용구 변환의 실제 반영과 안정화를 기다리고, 이미 일치하는 속성은 불필요하게 클릭하지 않습니다.
3. 서식 중 사용자 입력·커서 이동과 원문 추가를 감지해 현재 원고를 보존합니다. 자동 롤백 중의 입력과 확인 지연도 복구 안내로 처리합니다.
4. 줄바꿈·서식 검증은 NBSP만 일반 공백으로 정규화하고 띄어쓰기의 위치와 수를 보존합니다. 변경하지 않은 문단도 정확히 검사합니다.
5. 사진 AI 설정은 지연 반영을 기다리며, 끝내 완료를 확인하지 못한 토글은 중복 실행하지 않습니다.
6. 예약 설정은 각 시간 선택의 안정화를 확인하고, 대기 중인 모드·날짜 변경이 있으면 복원 완료로 잘못 안내하지 않습니다.

검토에서 재현한 지연 조건과 사용자 편집·미확정 명령의 경계 조건을 모의 편집기 회귀 검사로 확인합니다. 새 지연 조건을 실제 네이버 원고에서 재현한 검수나 최종 발행은 수행하지 않았습니다. 심사 제출·공개 출시는 기존 사용자 지시에 따라 보류합니다.

### 0.1.28 · 전체 줄바꿈 중간 실패 대응

커서 이동 후 60ms, Enter 입력 후 150ms의 고정 대기 때문에 지연된 편집기 상태를 실패로 판단하는 경로와, 문단 DOM 재렌더링으로 대상을 잃어 전체 작업을 되돌리는 경로를 모의 재현하고 수정했습니다. 커서·문단 나누기의 실제 반영과 안정화를 제한 시간 안에서 확인하며 Enter는 중복 전송하지 않습니다. 문단이 다시 그려지면 동일한 네이버 고유 ID와 남은 원문·서식이 일치할 때만 대상을 다시 연결합니다. 완료된 Enter마다 실제 줄바꿈 위치를 검증합니다.

잘못 적용된 줄바꿈은 기존 원고로 복원합니다. 사용자 직접 입력 또는 아직 완료를 확인하지 못한 네이버 입력이 있으면 자동 되돌리기로 원고를 훼손하지 않도록 중단하고 복구 안내를 표시합니다. 이번 재현은 모의 편집기 지연·재렌더링 조건으로 수행했으며 사용자에게 보고된 실제 네이버 원고를 직접 재현한 검수는 아닙니다.

### 0.1.27 · 줄바꿈 미리보기 위치 표시

설정과 무관했던 고정 적용 예시를 실제 줄바꿈 계산 함수로 변경했습니다. 미리보기의 실제 줄바꿈 위치를 ↵로 표시합니다. 기본 ‘줄바꿈 위치’ 화면은 가로 스크롤로 문장을 보여 주며, ‘모바일 참고’에서 화면 폭에 따른 자동 줄바꿈을 확인할 수 있습니다. 변경 전후 본문 폭을 같게 맞추고, 부분 선택의 앞뒤 문맥과 문단 정렬을 보존합니다.

### 0.1.26 · 실패 복구와 사용성 재검수
작업 결과를 확인하지 못하면 사라지는 알림 외에 복구 안내를 유지합니다. 단순 연결 문제는 ‘연결 다시 확인’으로 재검사하고, 결과가 불확실한 작업은 네이버 본문을 확인한 뒤 상단 ‘저장’으로 임시저장합니다. 저장 완료를 확인하면 패널의 ‘저장한 글 새로고침’으로 현재 글쓰기 탭을 다시 연결할 수 있습니다. 저장 확인 후 본문·탭이 바뀌거나 업로드가 진행 중이면 새로고침을 막고 재확인을 안내합니다. 임시저장 완료 자체는 사용자가 네이버 화면에서 확인합니다.

실패 직후 상태 갱신, 응답 유실 후 중복 작업 차단, 링크 카드 이미지 완료 확인 대기(2초 → 8초), 짧은 화면의 복구 버튼 접근성을 개선했습니다. 자동 검사 **560개 / 43개 파일**과 타입·빌드·패키지 검사를 통과했습니다. [0.1.26 사용성 검수 보고서](docs/검증-보고서-0.1.26.html)에서 실제 연결 확인과 모의 오류 검수 범위를 구분합니다.
