네이버 블로그 편집 도우미 — 개발 전 디자인 검토
작성일: 2026-10-06
이 파일과 디자인 이미지는 화면 제안이며, 확장 프로그램 구현 또는 스마트에디터 연동 검증 결과가 아닙니다.

1. 전체 방향
기존 네이버 글쓰기 화면 옆에 Chrome 보조 패널을 둡니다. 기본 설계 폭은 400px 전후이며 작은 패널에서는 콘텐츠를 세로로 스크롤합니다. Chrome의 실제 패널 표시 방향과 크기에 따라 대응합니다. 패널에는 서식, 내 글, 사진, 줄바꿈 순서로 탭을 배치합니다. 하단 작업 버튼과 상단 선택 위치를 고정해 긴 목록에서도 대상과 동작을 함께 확인합니다.

2. 서식
본문·소제목·강조 프리셋을 먼저 선택하고 예시와 적용 속성을 확인합니다. 지정하지 않은 속성은 '유지'로 표시합니다. 프리셋 편집 시 변경할 속성만 활성화하는 제어를 제공합니다. 글자 속성과 문단 속성의 적용 대상을 구분합니다. 글자 크기 등 구체적인 옵션은 네이버의 실제 지원 목록을 읽고 검증한 뒤 확정합니다. 시안의 숫자는 화면 예시입니다.

3. 내 글
등록 자료 수와 추천 키워드를 표시합니다. 결과에는 제목·날짜·원문 발췌·일치 키워드·원문 열기·일반 링크 삽입을 제공합니다. 이미 삽입된 글을 표시하고 삽입 동작을 비활성화합니다. URL 직접 등록, 사용자가 연 내 글 등록, 파일 가져오기 경로를 제공합니다. '관련성'은 로컬 키워드 점수로 계산하며 AI 추천이나 의미 유사도 보장으로 표현하지 않습니다. 패널의 발췌와 자료 수는 모두 예시입니다.

4. 사진
사진 목록과 문단 목록을 한 패널 안에 배치합니다. 선택 사진 → 대상 문단 → 앞/뒤 → 이동 순으로 확인합니다. 새 사진은 위치를 먼저 정한 뒤 네이버 업로드 흐름으로 넘깁니다. 업로드 중 이동을 막습니다. 사진·캡션·속성·슬라이드 묶음의 보존은 실제 저장 결과로 검증합니다. 첫 버전 화면에는 문장 중간 삽입을 제공하지 않습니다. 사진을 삭제하거나 재업로드해 이동을 대신하지 않습니다.

5. 줄바꿈
선택 영역과 일반 본문을 명확히 구분합니다. 문장 단위, 긴 문장 기준, 빈 줄, 기존 줄바꿈 보존을 조절합니다. 미리보기에서 원문/결과를 함께 비교하고 선택한 범위만 적용합니다. 소제목·표·목록·인용·사진·캡션·링크 카드·코드는 제외합니다. 글자 수는 참고값이고 실제 모바일 줄 폭 보장으로 표현하지 않습니다. 일반 링크와 굵게·색상 등 서식을 보존한 상태에서 되돌리기를 검증해야 합니다.

6. 설정 및 백업
서식, 블로그 주소, 줄바꿈 규칙, 백업을 관리합니다. 내보내기 항목을 선택하고 가져오기 전 개수·설정 처리 방식·갱신 계획을 확인합니다. URL 정규화로 중복을 판단하고 수집 시각을 확인해 자료를 갱신합니다. 원치 않는 기존 설정 교체를 막습니다. 비밀번호·쿠키·세션 정보를 백업에 넣지 않습니다.

7. 작업 상태
선택이 없으면 본문 선택을 안내하고 적용을 막습니다. 문서가 바뀌어 위치를 식별하지 못하면 재선택을 안내합니다. 내 글 자료가 없으면 URL 등록과 파일 가져오기를 보여줍니다. 사진 업로드가 끝나기 전에는 이동 버튼을 비활성화합니다. 지원하지 않는 편집기는 변경하지 않고 안내합니다.

8. 구현 전에 확인할 항목
현재 글 읽기, 선택 영역 기억, 서식 적용, 일반 링크 삽입, 사진 한 장 이동, 텍스트 문단 분할을 작은 실험으로 확인합니다. 각 동작은 적용 → 임시저장 → 다시 열기 순으로 검증합니다. 저장 보존·취소·서식 있는 복원·사진 캡션 보존이 통과하기 전에는 완료로 표시하지 않습니다. 이 디자인 단계에서는 실제 네이버 초안에 접근하거나 내용을 변경하지 않습니다.
