심사 담당자 테스트 안내 · 글부기 0.1.29

목적
PC 네이버 블로그 글쓰기의 반복 편집을 돕는 도구입니다. 최종 저장·발행은 네이버 UI에서 사용자가 실행합니다.

실제 네이버 테스트
1. Chrome에 설치하고 심사자 자신의 네이버 계정으로 로그인합니다. 개발자의 계정·비밀번호를 제공하거나 공유하지 않습니다.
2. PC 네이버 블로그에서 새 테스트 글을 엽니다. 예: '첫 번째 문장입니다. 두 번째 문장도 보존합니다.'
3. 확장 아이콘으로 사이드 패널을 열고 글자를 드래그한 뒤 본문·소제목·강조 서식을 적용합니다. 되돌리기로 복원합니다.
4. 본문 문단을 클릭하고 인용구 프리셋 및 모양을 골라 적용합니다. 원문 보존을 확인하고 되돌립니다.
5. 줄바꿈 탭에서 변경 전후를 미리보기한 뒤 적용합니다. 문장·구절 우선은 문장을 무조건 일정 글자 수로 자르지 않습니다.
6. 내 글 검색은 설정에 심사자 자신의 블로그 주소를 저장한 뒤 검색합니다. 공개 글이 없으면 저장한 글 자료를 직접 등록하는 흐름으로 확인할 수 있습니다.
7. 사진이 필요하면 심사자가 준비한 테스트 이미지만 사용합니다. 사진이 많은 글을 다시 열면 자동 확인 후 원래 위치로 복귀하는지 확인합니다.
8. 예약 탭은 예약 날짜·시간만 네이버 기본 화면에 설정합니다. 실제 발행을 누를 필요는 없습니다.
9. 설정에서 개인정보처리방침 링크 및 JSON 내보내기/가져오기를 확인합니다.

로그인 없는 UI 참고
설치된 확장의 index.html은 예시 문서 미리보기입니다. 실제 네이버에 연결되었음을 의미하지 않으며 도킹 패널·네이버 연동 검수와 구분합니다. 스토어 스크린샷도 이 예시 화면을 사용합니다.

주의
테스트 원고만 사용하고 공개 발행은 실행하지 마세요. 기존 개인 초안이나 공개 글을 변경할 필요가 없습니다. 네이버 로그인·추가 본인 인증은 네이버 계정 소유자가 직접 수행합니다.

0.1.26 복구 안내 확인
패널 아래 ‘연결·복구 도움말’을 열어 안내를 확인합니다. 네이버 상단의 ‘저장’은 임시저장이며, 완료 안내를 확인한 뒤 체크해야 새로고침 버튼이 활성화됩니다. 저장 확인 뒤 본문이 바뀌거나 다른 탭을 선택하거나 사진 업로드가 진행 중이면 새로고침을 거절합니다. 새로 연결한 뒤 적용 위치를 다시 선택합니다. 작업 결과가 이미 반영되어 있으면 같은 삽입을 반복하지 않습니다. 불확실한 결과를 억지로 재현하기 위해 개인 원고를 변경할 필요는 없습니다.

0.1.28 전체 줄바꿈 확인
- 긴 일반 본문에 줄바꿈을 적용해 미리보기의 ↵ 위치와 비교합니다.
- 커서와 Enter의 실제 반영을 기다리고, 편집기가 문단 요소를 다시 그려도 고유 ID와 원문이 일치하면 계속합니다.
- 작업 중 직접 입력이 감지되거나 입력 결과가 아직 불명확하면 원고를 보존하고 복구 안내를 표시합니다.
- 모의 지연·재렌더링 회귀 검사를 통과했으며 사용자에게 보고된 실제 원고는 이번에 직접 재현하지 않았습니다.

0.1.29 신뢰성 문제 6건 수정
- 되돌리기·서식 적용은 네이버의 실제 반영이 확인된 뒤 다음 명령으로 진행합니다.
- 서식 중 사용자 입력이 있으면 현재 원고를 보존하며 자동 롤백하지 않습니다.
- 사진 AI·예약 변경은 지연 반영을 기다립니다. 완료가 불명확하면 원래 명령이 남아 있을 수 있어 중복 실행을 막고 복구 안내로 전환합니다.
- 줄바꿈·서식 검증은 NBSP를 일반 공백으로 정규화하되 공백의 삭제·이동을 검출합니다.
- 기존 지연 재현 6건과 미확정·입력 경합 경계 조건의 회귀 검사를 포함합니다. 새 지연 조건은 모의 편집기로 검증했으며 실제 네이버 글의 최종 발행은 실행하지 않았습니다.
