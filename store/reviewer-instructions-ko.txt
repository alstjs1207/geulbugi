심사 담당자 테스트 안내 · 글부기 1.2.1

목적과 사용 환경
PC Chrome 116 이상의 네이버 블로그 글쓰기 화면에서 반복 편집을 돕는 사이드 패널 확장 프로그램입니다. 글부기 자체의 가입·결제는 없으며, 실제 네이버 연동에는 심사자 본인의 네이버 로그인과 새 테스트 글이 필요합니다. 개발자의 계정·비밀번호를 제공하거나 공유하지 않습니다. 최종 저장·발행은 네이버 화면에서 사용자가 실행합니다.

기본 테스트
1. 설치 후 패널 하단의 버전이 1.2.1인지 확인하고 PC 네이버 블로그에서 새 테스트 글을 엽니다. 예: '첫 번째 문장입니다. 두 번째 문장도 보존합니다.'
2. 확장 아이콘으로 사이드 패널을 열고 글자를 드래그해 본문·소제목·강조 서식을 적용합니다. 본문 문단에서는 인용구 프리셋과 모양도 선택할 수 있습니다. 원문 보존과 직전 작업 되돌리기를 확인합니다.
3. 설정 → 프리셋 단축키에서 최대 8개 슬롯에 서식·인용구 프리셋을 연결하고, '크롬에서 키 조합 지정'으로 키를 직접 지정합니다. 본문 선택 후 단축키 적용을 확인합니다. 보조키만 누른 동작이 직접 편집으로 판정되어 불필요한 복구 안내를 표시하지 않는지 확인합니다.
4. 기능 탭을 전환하면 내용 스크롤이 상단으로 돌아오는지 확인합니다. 다른 탭을 선택했을 때 실행 대상과 연결 안내를 확인한 뒤 올바른 글쓰기 탭에서 작업합니다.
5. 줄바꿈 탭에서 변경 전후와 ↵ 위치를 확인한 뒤 적용합니다. 문장·구절 우선은 안전한 경계가 없는 문장을 유지합니다. 실제 모바일 줄 폭은 네이버 모바일 미리보기에서 별도로 확인합니다.
6. 설정에 본인 블로그 주소를 저장하고 내 글 탭에서 최근 공개 글 최대 10개와 새로고침을 확인합니다. 네이버 블로그 탭을 열어 실제 카테고리·하위 분류를 불러오고, 분류 선택 시 해당 분류의 최근 글만 나오는지 확인합니다.
7. 키워드 검색은 선택한 분류와 관계없이 전체 카테고리를 최근 작성일순으로 검색합니다. '최근 글 보기'로 최근 목록에 복귀합니다. 공개 글이 적으면 있는 만큼 표시되며, 공개 글이 없으면 저장한 글 자료를 직접 등록해 확인할 수 있습니다.
8. 본문에서 삽입 위치를 한 번 선택하고 링크 미리보기를 넣습니다. 본문을 다시 클릭하지 않고 다음 링크를 넣어 카드 뒤에 이어지는지, 기존 문구·서식·카드 순서가 유지되는지, 마지막 카드만 되돌릴 수 있는지 확인합니다.
9. 심사자가 준비한 테스트 사진으로 문단 앞뒤 이동·새 사진 추가·사진 AI 활용 설정을 확인합니다. 사진이 많은 글을 다시 열면 화면 밖 사진을 확인한 뒤 원래 위치로 복귀하며, 확인 중 직접 입력하거나 스크롤하면 중단됩니다.
10. 예약 탭에서 날짜·시간을 네이버 기본 화면에 설정합니다. 실제 발행을 누를 필요는 없습니다. 설정에서 개인정보처리방침 링크와 JSON 내보내기·미리보기·가져오기를 확인합니다.

1.2.1 빠른 선택·서식·이어 쓰기 확인
- 테스트 문구를 선택해 서식을 적용한 직후 본문의 다른 위치를 클릭해 커서를 옮깁니다.
- 서식 적용이 완료되고 원래 선택 영역의 서식·원문·사진이 보존된 경우, 커서 이동만으로 복구 안내가 표시되지 않고 새 커서 위치와 직전 작업 되돌리기가 유지되는지 확인합니다.
- 전체 적용과 원문·사진·선택 밖 서식 보존을 확인한 뒤 바로 방향키로 커서를 옮기거나 입력했을 때 정상적으로 이어 쓰는지 확인합니다. 직접 입력 뒤의 안전하지 않은 되돌리기는 차단합니다. 부분 적용·결과 미확정 상황에서는 기존 보호가 유지됩니다.
- 줄바꿈 보존 체크박스를 빠르게 끔→켬으로 조작하고 새로고침한 뒤 최종 값이 유지되는지 확인합니다. 다른 글로 전환한 뒤 이전 응답이 현재 패널을 덮어쓰지 않는지도 확인합니다.

연결·복구 안내 확인
패널 아래 '연결·복구 도움말'에서 절차를 확인합니다. 단순 연결 문제는 '연결 다시 확인'으로 재검사합니다. 작업 결과를 확인하지 못하면 본문부터 확인하고, 네이버 상단 '저장'(임시저장)의 완료 안내를 확인한 뒤 체크해야 '저장한 글 새로고침'을 실행할 수 있습니다. 저장 확인 후 본문 변경·다른 탭 선택·사진 업로드 중에는 새로고침을 거절합니다. 결과가 이미 반영된 작업을 중복 삽입하지 않도록 안내합니다.

로그인 없는 UI 참고
설치된 확장의 index.html은 예시 문서 미리보기입니다. 실제 네이버 연결이나 도킹 패널의 동작을 검증한 것으로 간주하지 않습니다. 스토어 스크린샷도 이 예시 화면을 사용하며 개인 원고나 로그인 정보를 포함하지 않습니다.

데이터와 권한
설정·등록한 공개 글·링크 카드 참조는 로컬에 저장하고 본문과 선택 영역은 기기에서 처리합니다. 내 글 조회·카테고리·검색·링크 카드·사진 업로드에는 네이버 통신이 필요합니다. 권한은 storage·sidePanel과 네이버 블로그 두 호스트이며, 운영자 서버·광고·분석 서비스·AI API로 원고를 전송하지 않습니다.

주의
테스트 원고만 사용하고 공개 발행은 실행하지 마세요. 기존 개인 초안이나 공개 글을 변경할 필요가 없습니다. 네이버 로그인·추가 본인 인증은 계정 소유자가 직접 수행합니다. 위 내용은 심사 시 확인할 절차이며, 이번 자료 정리에서 실제 네이버 테스트를 새로 수행했다는 기록은 아닙니다.

1.2.1 프로필 글쓰기 연결 확인
내 블로그 프로필의 글쓰기로 진입하고 글부기 패널이 자동으로 현재 글을 표시하는지 확인하세요. 프로필 글쓰기와 상단 글쓰기 경로를 모두 지원합니다.
