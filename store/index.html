1.2.1 프로필 글쓰기 자동 연결

프로필 글쓰기가 여는 별도 편집기 경로를 인식하고, 편집기 등록 후 패널 연결을 자동 갱신합니다. 1.2.1은 로컬 준비 상태이며 스토어에 업로드하거나 제출하지 않았습니다. 아래 1.2.0의 검토 제출 이력과 구분합니다.

현재 공개 버전은 1.1.2입니다(2026-11-11 대시보드·공개 페이지 확인). 이 날짜는 자료 정리일이며 실제 출시일을 뜻하지 않습니다. 2026-11-11 초안 1.2.0을 확인하고 소개·개인정보·심사 안내를 저장·재확인한 뒤 검토에 제출했습니다. 현재 검토 대기 중이며 승인 후 자동 게시됩니다. 업로드된 CRX 내용과 해시는 독립 비교하지 않았습니다.

2026-11-11 사용자 명시 지시로 이전 보류를 해제하고 문구 반영·검토 제출을 완료했습니다. 1.2.0 실제 공개 확인은 남아 있습니다. 남은 작업에서 상태를 관리합니다.

1.2.0 빠른 편집·안정성 개선

선택 추적의 반복 읽기와 서식 완료 고정 대기를 줄였습니다. 체크박스 연속 조작 유실과 이전 편집·단축키 응답의 상태 역전을 수정했습니다. 전체 적용과 원문·사진·선택 밖 서식 보존을 검증한 뒤 바로 입력할 수 있습니다. 1.2.0은 실제 대시보드에서 검토 대기 중으로 확인했으며 승인 후 자동 게시가 설정됐습니다. 현재 공개 페이지는 1.1.2입니다.

기존 서식 적용 후 커서 이동 개선

서식 적용 직후 본문을 클릭해 커서를 옮겼을 때, 적용이 끝났는데도 복구 안내가 표시되던 문제를 수정했습니다. 원래 선택 영역의 서식·원문·사진 보존을 확인한 뒤 새 커서 위치와 직전 작업 되돌리기를 유지합니다. 부분 적용이나 직접 입력은 기존처럼 보호합니다.

내 글 탐색과 단축키

내 글 탭에서 최근 공개 글을 최대 10개 표시합니다. 네이버 블로그 탭이 열려 있으면 실제 카테고리와 하위 분류별 최근 글을 조회할 수 있습니다. 키워드 검색은 전체 카테고리를 최근 작성일순으로 검색하고, '최근 글 보기'로 최근 목록에 복귀합니다. 본문 위치를 다시 선택하지 않고 링크 카드를 연속 삽입할 수 있습니다.

최대 8개 단축키 슬롯에 서식·인용구 프리셋을 연결합니다. 단축키 연결 상태 갱신, 실행 대상 탭 유지, 기능 탭 전환 시 스크롤 상단 복귀와 빠른 입력 중 보조키를 직접 편집으로 오인하던 문제의 수정이 포함되어 있습니다.

편집·미리보기·복구

서식·인용구, 사진 이동·추가·AI 활용 설정, 의미를 살린 줄바꿈 미리보기와 예약 날짜·시간 설정을 제공합니다. 최종 저장·발행은 네이버 화면에서 직접 실행합니다. 결과가 불확실한 작업은 본문 확인 → 네이버 상단 '저장'(임시저장) → 저장 완료 확인 → '저장한 글 새로고침' 순서로 복구합니다.
