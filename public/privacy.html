글부기

개인정보처리방침

글부기는 PC Chrome의 네이버 블로그 편집 작업을 돕습니다. 본문 편집은 사용자 기기에서 처리하며, 운영자의 서버·분석 서비스·AI 서비스로 본문이나 설정을 보내지 않습니다. 내 글 검색·원문 조회·링크 카드·사진 업로드는 사용자가 선택한 기능을 제공하기 위해 네이버와 통신합니다.

1. 처리하는 정보와 목적

정보목적과 저장
열린 네이버 글의 제목·본문·서식·선택 영역·사진 주소·캡션·링크·예약 설정편집 위치 파악, 서식·줄바꿈·사진 이동, 결과 확인과 직전 작업 되돌리기에 사용합니다. 편집기 연결 중 메모리에서 처리하며, 원고 전체를 도우미의 영구 저장소나 설정 백업에 저장하지 않습니다.
직접 설정한 블로그 주소, 서식 프리셋, 단축키 연결, 줄바꿈·예약 기본값기능 설정을 유지하기 위해 Chrome의 기기 내 저장소(chrome.storage.local)에 저장합니다.
사용자가 등록하거나 가져온 공개 글 주소·제목·태그·일부 발췌·발행일·수집일저장한 글 검색과 링크 카드 삽입을 위해 기기에 저장합니다. 공개 검색 결과 자체는 사용자가 등록하지 않으면 저장하지 않습니다.
삽입한 링크 카드의 구성요소 ID·원문 주소·내용 식별값네이버가 카드 주소를 화면에 표시하지 않는 경우에도 원래 주소를 확인하기 위한 로컬 참조입니다. 최근 최대 1,000개를 유지합니다.
사용자가 선택한 사진 파일, 백업 JSON선택한 사진은 네이버의 기본 업로드 기능으로 전달합니다. JSON은 가져오기·내보내기 용도로 처리합니다. 도우미는 사진 원본을 영구 보관하지 않습니다.
현재 네이버 탭 주소와 편집 프레임 식별자올바른 편집기에 요청을 전달하는 데 사용합니다. 임시 연결 정보는 Chrome 세션 저장소에서 관리하며 탭을 닫으면 해당 연결 기록을 제거합니다.

2. 외부 통신과 공유

내 글 검색은 설정한 블로그 주소와 사용자가 입력하거나 선택한 검색어를 네이버 HTTPS 검색 주소로 보냅니다. 원문 조회는 선택한 공개 게시글 주소에 요청합니다. 이 공개 조회 요청에는 도우미가 로그인 자격 증명을 첨부하지 않습니다.

링크 카드 생성·사진 업로드·예약 시간 설정은 사용자가 로그인한 네이버 편집기의 기본 기능을 이용합니다. 사진·미리보기 표시는 네이버와 이미지 제공 서버에 리소스 요청을 일으킬 수 있습니다. 네이버가 처리하는 로그인, 업로드, 저장 및 발행에는 네이버 개인정보처리방침이 적용됩니다. 도우미가 비밀번호·인증 쿠키를 직접 읽거나 저장하는 기능은 없습니다.

운영자는 도우미를 통해 처리한 데이터를 판매하거나 광고 목적으로 사용하지 않습니다. 별도 분석·광고·오류 수집 SDK, 개발자 운영 서버, AI API를 사용하지 않습니다. 모든 실행 코드는 설치 패키지에 포함됩니다.

3. 보관과 삭제

설정·프리셋·등록 글은 해당 Chrome 프로필에 유지됩니다. 도우미에서 프리셋·등록 글을 삭제할 수 있으며, 모든 로컬 저장 자료를 제거하려면 Chrome 확장 프로그램 관리 화면에서 이 확장을 제거하세요. 확장을 비활성화하는 것만으로 저장 자료가 삭제되지는 않습니다.

링크 카드 참조는 최대 1,000개까지 유지하고 새 참조가 추가되면 오래된 항목부터 제거합니다. 편집 탭을 닫거나 새로고침하면 메모리의 본문 스냅샷·선택 영역·되돌리기 기록을 더 이상 사용하지 않습니다. 네이버의 임시저장 글과 게시글은 확장을 제거해도 남으며 네이버에서 따로 관리해야 합니다.

내보낸 JSON 파일은 사용자가 지정한 다운로드 위치에 남습니다. 필요한 경우 해당 파일도 직접 삭제하세요. 백업에는 블로그 주소와 등록 글의 발췌 등이 포함될 수 있으므로 공유할 때 내용을 확인해 주세요.

4. 권한 사용

storage는 로컬 설정과 임시 편집 연결 정보를, sidePanel은 편집 도구 패널을 열기 위해 사용합니다. 네이버 탭 연결에는 네이버 블로그 호스트 권한을 이용합니다. 네이버 블로그 호스트 접근은 편집기 내용 읽기·편집 및 공개 글 조회에 사용합니다. 전체 웹사이트·브라우저 방문 기록·비밀번호 저장소 접근 권한을 요청하지 않습니다.
